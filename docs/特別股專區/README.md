# 特別股專區頁面作業須知與功能設計規範 (Preferred Stocks)

- **路由端點**：`/preferred-stocks`
- **頁面檔案**：`app/pages/preferred-stocks.vue`
- **卡片元件**：`app/components/preferred/PreferredStockCard.vue`
- **當前資料狀態**：**目前尚無真實後端即時 API 端點**。頁面內容採用手選之真實台股特別股（如國泰金甲特、富邦金乙特）作為靜態驗證資料（Fixture），專供驗證卡片欄位排版與資訊架構，**非即時報價**。

---

## 1. 頁面定位與免責聲明宣告

本專區專為尋求高於銀行定存、低於普通股波動的退休穩健族群設計。依據 [[三水桶資產配置策略 (Three-Bucket Strategy)]]，特別股是填補「第 2 水桶（中期收益艙，4–8 年資金）」的優良防禦工具。

> ⚠️ **前端頂部常駐提示**：
> 在尚未串接真實即時報價端點前，頁面頂部必須常駐醒目標籤：
> `【提示：本專區目前展示之特別股條款與價格為靜態驗證資料 (Fixture)，非盤中即時報價，僅供產品介面功能體驗】`

---

## 2. 特別股卡片核心欄位與條款解構 (`PreferredStockCard.vue`)

依據 [[特別股契約與評價模型]]，特別股卡片切忌僅僅顯示股價與殖利率，必須完整呈現五大核心契約維度：

```
+─────────────────────────────────────────────────────────────+
| 【股票名稱與代碼】 (例如: 2882A 國泰金甲特)  [固定股息: 3.80%] |
+─────────────────────────────────────────────────────────────+
| 契約條款架構:                                               |
|  - 股息累積性: 【非累積型】 (當期未發放未來不補發)            |
|  - 剩餘分配權: 【非參與型】 (不參與普通股超額盈餘分配)        |
|  - 清算優先權: 【次順位債券之後、普通股之前】                |
|  - 發行人贖回權: 【發行滿 7 年後有權按票面價 60 元強制買回】   |
+─────────────────────────────────────────────────────────────+
| 核心估值與風險指標:                                         |
|  - 現價: 60.5 元   - 最差殖利率 (YTW): 3.65%                |
|  - 距贖回日: 剩餘 1 年 4 個月  - 溢價率: +0.83%             |
+─────────────────────────────────────────────────────────────+
```

| 條款維度項目 | 欄位呈現規範 | 前端金融邏輯與風險警示 |
| :--- | :--- | :--- |
| **股息累積性 (Cumulative)** | 標註 `累積型` 或 `非累積型` 徽章 | 非累積型在金控虧損年份若停發股息，未來無須補發，退休族需特別留意。 |
| **股息參與權 (Participating)** | 標註 `參與型` 或 `非參與型` 徽章 | 非參與型僅領取固定票面股息，無法分享金控高獲利年的超額股利。 |
| **最差殖利率 (YTW)** | 大字呈現 **YTW (Yield to Worst)** | **核心定價指標**。比對「持有至到期」與「發行人於首個贖回日買回」之年化回報，取其較低者作為保守收益率，避免高估實質回報。 |
| **發行人贖回權 (Callable)** | 顯示「首個贖回日」與「剩餘年限」 | 揭露發行人之強制買回權力（通常為票面價 50 元或 60 元）。 |
| **負凸性警示 (Negative Convexity)** | 當現價顯著高於票面贖回價（溢價 $> 2\%$）時觸發 | 彈出溫和提示：「**負凸性警示**：市價高於發行人贖回價，一旦發行人行使買回權，投資人將承擔溢價虧損，資本利得空間受限」。 |

## 3. UI/UX 與無障礙工程約束

- **深色卡片階梯**：卡片背景採用 `1dp Elevation` 即 `#1E1E1E`，邊界配置 1px `#333333` 邊框，確保在 `#121212` 底色上具備足夠幾何邊界對比。詳見 [[Material 深色高度受光與文字透明度模型]]。
- **高齡字級標準**：卡片內部所有條款說明文字嚴格遵守 **$\ge 16\text{px}$**，禁止為了塞入更多條款而將字級縮小至 12px–13px。
- **360px 零破版佈局**：在 360px 手機寬度下，卡片採用縱向單欄佈局，條款標籤自動換行（`flex-wrap`），點擊展開完整條款之按鈕高度維持 **48px**。詳見 [[高齡友善排版與觸控熱區規範]]。
- **強制色彩自適應**：卡片邊框預埋 `border: 1px solid transparent`，相容於 Windows 高對比模式。詳見 [[Windows 強制色彩模式防禦技術]]。
