# 總覽頁面作業須知與功能設計規範 (Dashboard)

- **路由端點**：`/dashboard`
- **頁面檔案**：`app/pages/dashboard.vue`
- **卡片顯示設定**：`app/composables/dashboard/useDashboardCards.ts`
- **雙軌模式切換**：`app/composables/dashboard/useDashboardExperienceMode.ts`

---

## 1. 頁面定位與核心架構哲學

總覽頁面是面向存股與退休投資人的首頁入口。本頁面的設計核心並非彭博終端機式的資訊轟炸，而是依據 [[雙軌自適應儀表板架構 (Adaptive Dual-Track)]] 與 [[金融數據降噪哲學 (Noise Elimination)]]，協助投資人建立平靜、確定性的資產心理防線。

```
+─────────────────────────────────────────────────────────────+
| 全域頂部切換列: [ 💡 小白防禦模式 (預設)  |  🔬 專家量化控制台 ] |
+─────────────────────────────────────────────────────────────+
                               │
       ┌───────────────────────┴───────────────────────┐
       ▼                                               ▼
【小白防禦模式視圖 (Novice)】                   【專家量化控制台視圖 (Expert)】
  1. 生活費安全存續跑道 (至幾歲)                   1. 穿透式風格因子暴露 (價值/規模/低波)
  2. 被動現金流發放日曆 (當月入帳)                 2. 債券有效存續期 (Duration) 與利差矩陣
  3. 觀察清單除權息倒數卡片                       3. [[Guyton-Klinger 動態提領護欄模型]] 帶狀圖
  4. 個股客觀健檢 (F-Score / Z-Score)             4. 歷史最大回撤 (MDD) 與水下修復期
  5. 估值排行與營收排行                           5. 蒙地卡羅萬次隨機路徑扇形圖
```

## 2. 現有功能卡片作業須知與資料規範

所有卡片元件均需遵守「絕不用假資料填版面」原則，各卡片之詳細規範如下：

### 卡片 A：估值排行 (Valuation Rankings)
- **資料性質**：真實後端資料。
- **欄位指標**：代號、名稱、股價、P/E、P/B、現金殖利率。
- **前端呈現規範**：
  - 嚴格遵守 [[多維視覺冗餘編碼 (Visual Redundancy)]]，漲跌數值旁必須配置顯式 `+` / `-` 符號與 ▲ / ▼ 幾何圖標。
  - P/B 破淨標的（P/B $< 1.0$）標註特殊中性徽章，引導理解 [[PBR 1倍破淨機制與資本收益性]]。

### 卡片 B：月營收排行 (Monthly Revenue Rankings)
- **資料性質**：真實後端資料。
- **欄位指標**：代號、名稱、當月營收、月增率 (MoM)、年增率 (YoY)、連增月數。
- **設計考量**：
  - 突顯連續 3 個月以上營收 YoY 正成長之標的，結合 [[營運槓桿與產能利用率效應]] 識別本業動能。
  - 標註「台股每月 10 日前更新」，若未公告則顯示佔位符號 `─`，嚴禁補零。

### 卡片 C：個股健檢 (Fundamental Health Check)
- **資料性質**：真實後端資料，搜尋單一股票即時計算輸出。
- **底層演算法對齊**：
  - **[[Piotroski F-Score 評分模型]]**：以 0–9 分呈現，評分 $\ge 8$ 標註綠色健康，$\le 3$ 標註紅色警示，並特別呈現「$\text{CFO} > \text{淨利}$」的會計防禦狀態。
  - **[[Altman Z-Score 破產預警模型]]**：區分為安全區（$\ge 2.99$）、灰色警戒區（$1.81 \le Z < 2.99$）與破產懸崖區（$< 1.81$）。
  - **[[KY 股法證會計檢驗架構]]**：若查詢標的為 KY 股，強制加註「境外第一上市審計警語」與「存貸雙高」檢驗項。

### 卡片 D：觀察清單近期除權息 (Ex-Dividend Notices)
- **資料性質**：真實後端資料，僅列出使用者觀察清單（`watchlist`）中有排定除權息之股票。
- **稅務與健保提示**：
  - 依據 [[台灣證券稅制與所得分離最佳化]]，當預估單次 54C 股利金額 $\ge 20,000$ 元時，卡片自動顯示提示：「預估扣繳 2.11% 二代健保補充保費」。

## 3. 雙軌模式切換開發指引 (`useDashboardExperienceMode.ts`)

目前該切換按鈕僅為功能殼，後續開發需落實以下階段規劃：

### 階段一：狀態持久化與版面自適應
- 使用者切換模式後，將設定值持久化至 `localStorage`（如 `dashboard_mode: 'novice' | 'expert'`）。
- **小白模式 (Novice)**：
  - 隱藏複雜統計圖表，將預設卡片收斂為 4 組核心卡片。
  - 字級全面採用 18px 基準，卡片內距使用標準 Spacing Token `--space-6` (24px)。
- **專家模式 (Expert)**：
  - 開放高階卡片（資產配置穿透、動態提領護欄、因子暴露矩陣）。
  - 提供資料列密集模式（Compact View）切換選項。

## 4. 前端工程與無障礙剛性約束

- **深色卡片 Elevation**：卡片背景一律採用 `1dp Elevation` 即 `#1E1E1E`（在 `#121212` 基底上疊加 5% 白色覆蓋層）。詳見 [[Material 深色高度受光與文字透明度模型]]。
- **文字對比與字級**：標題採用 87% 白色（`#E0E0E0`），次要文字採用 60% 白色（`#A0A0A0`），字級下限一律 $\ge 16\text{px}$。
- **360px 視窗自適應**：在寬度 360px 下，卡片格線自動轉為單欄縱向排列（`grid-cols-1`），嚴禁出現水平捲軸。詳見 [[高齡友善排版與觸控熱區規範]]。
- **法規免責標註**：頁面底部必須顯式放置免責宣告：「本頁面提供之客觀排行與指標統計僅供研究參考，非屬投顧法之推薦買賣建議，使用者應獨立審慎評估風險」。詳見 [[投顧法第 4 條安全港與釋字 634 號邊界]]。
