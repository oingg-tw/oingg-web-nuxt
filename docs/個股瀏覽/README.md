# 個股瀏覽頁面作業須知與功能設計規範 (Stock Detail)

- **路由端點**：`/stock/[code]`（動態路由，例如 `/stock/2330`）
- **頁面檔案**：`app/pages/stock/[code].vue`
- **卡片自訂管理**：`app/composables/stock/useStockCards.ts`
- **進入路徑**：全域搜尋列（`StockSearchBar.vue`）或點擊任何報價列表/卡片跳轉進入（未收錄於頂部導航列）。

---

## 1. 頁面決策資訊架構 (Decision Hierarchy)

本頁面嚴格依據 [[常態化獲利與財報回溯年限]] 中確立的「存股與退休投資人決策認知鏈」，由頂至底依序劃分為四大區塊：

```
+─────────────────────────────────────────────────────────────+
| 【0. 核心即時摘要卡】(StockSummaryCard.vue) - 永遠常駐頂部   |
|  - 公司 Logo、現價、多維漲跌、殖利率、本益比、本淨比        |
+─────────────────────────────────────────────────────────────+
                               │
                               ▼
+─────────────────────────────────────────────────────────────+
| 【1. 估值河流圖區塊】(Valuation River Charts)                |
|  - 本益比 (P/E) 河流圖 / 本淨比 (P/B) 河流圖 (目前為結構殼)  |
+─────────────────────────────────────────────────────────────+
                               │
                               ▼
+─────────────────────────────────────────────────────────────+
| 【2. 財務營運體質區塊】(Financial Quality & Dilution)        |
|  - 股本變化階梯折線圖 (真實資料) ──► 檢驗是否假成長真稀釋    |
|  - 下次除權息即時提醒 (真實資料) ──► 健保 2 萬元門檻提示     |
|  - 近四季 EPS、月營收年增率 (目前為結構殼)                  |
+─────────────────────────────────────────────────────────────+
                               │
                               ▼
+─────────────────────────────────────────────────────────────+
| 【3. 公司基本資料區塊】(Company Profile)                     |
|  - 產業次類別、成立年限、董監持股、重大官方訊息              |
+─────────────────────────────────────────────────────────────+
```

## 2. 核心元件規範與「絕不用假資料」鐵律

本頁面是全站體現「**絕不用假數字填版面**」最高工程原則的核心陣地：

### 一、摘要卡 (StockSummaryCard.vue)
- **資料性質**：真實後端資料，不受卡片顯示設定影響，永遠常駐於頂部。
- **公司 Logo 規範**：
  - 透過 `company_profile.website` 欄位正規化後調用 Brandfetch API（邏輯位於 `app/utils/company-logo.ts`）。
  - **防破圖防禦**：查無 Logo 或載入失敗時，直接優雅隱藏，嚴禁顯示瀏覽器預設破圖圖示。
- **KY 股高風險旗標**：
  - 檢驗代碼是否帶有 `-KY`，若為境外第一上市，強制並列「KY 股審計預警標籤」，引導投資人防範 [[KY 股法證會計檢驗架構]] 中的存貸雙高地雷。

### 二、股本變化階梯圖 (`useCapitalStockHistory.ts`，真實資料)
- **金融本質**：檢驗 EPS 成長是來自本業獲利擴張，還是透過現金增資或資本公積轉增資造成的股本虛胖。
- **指標對齊**：
  - 深度呼應 [[Piotroski F-Score 評分模型]] 第 7 項「直近期內無發行新股稀釋」與巴菲特 5 年保留盈餘原則。
  - 圖表採用「階梯折線圖（Stepped Line）」，清楚標註每次股本異動來源（如「2024Q2 現金增資 10%」）。

### 三、下次除權息公告 (`useExDividendNotices.ts`，真實資料)
- 呈現最近一筆未來除權息事件（除息日、發放日、每股現金股利）。
- 整合 [[台灣證券稅制與所得分離最佳化]]，提示單次領息滿 2 萬元之二代健保預扣門檻。

### 四、河流圖與財務數據骨架殼 (`StockChartShell.vue`)
- 在後端尚未提供穩定歷年本益比河流圖與四季 EPS 端點前，**一律渲染骨架殼**，標記「資料庫歷史端點整合中，尚未提供」，禁止用 Mock 隨機函數產生波狀假曲線。

## 3. SEO 與 E-E-A-T 結構化資料工程

個股頁面承載了全站大部分長尾自然搜尋流量，必須落實 [[金融 YMYL 內容與 E-E-A-T 信任架構]]：
- **動態 SSR 水合**：首屏個股財務數據必須在伺服器端完成 SSR 渲染，確保 Googlebot 能即刻爬取收錄。
- **JSON-LD 注入**：動態注入 `FinancialProduct` 與 `BreadcrumbList`，標記官方交易所數據授權來源（TWSE / TPEx）。
- **規範網址**：部署標準 Self-referencing Canonical：
  `<link rel="canonical" href="https://oingg.com/stock/2330" />`，消除任何大小寫或尾部參數引起的重複內容。

## 4. UI/UX 與高齡人因工程約束

- **360px 手機寬度適應**：
  - 在 360px 視窗下，頂部摘要卡自動重組為垂直緊湊流，關鍵股價與漲跌幅維持 **24px 粗體**，確保長者一目了然。詳見 [[高齡友善排版與觸控熱區規範]]。
- **多維冗餘色彩**：
  - 股價漲跌數值旁強制配置顯式正負號與 ▲/▼ 圖標，符合 [[多維視覺冗餘編碼 (Visual Redundancy)]]。
- **深色模式對比**：
  - 河流圖背景採用 `#121212`，河流通道區間線設定 3:1 對比度，正文維持 87% 白色不透明度。詳見 [[Material 深色高度受光與文字透明度模型]]。
