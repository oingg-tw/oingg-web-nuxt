# 觀察清單頁面作業須知與功能設計規範 (Watchlist)

- **路由端點**：`/watchlist`
- **頁面檔案**：`app/pages/watchlist.vue`
- **核心狀態管理**：`app/composables/stock/useStocks.ts` 中的 `watchlist` state。
- **主要元件清單**：
  - `components/stock/StockTable.vue` — 桌機版資料表格
  - `components/stock/StockCard.vue` — 行動版資料卡片
  - `components/stock/StockListActions.vue` — 欄位自訂與批次操作工具列

---

## 1. 頁面定位與資訊架構

觀察清單是使用者存放「有興趣、長期追蹤研究但尚未實際持有」的標的池。本頁面的設計核心在於提供清晰、可自訂的指標對照，並依據 [[金融數據降噪哲學 (Noise Elimination)]]，刻意排除誘發短線投機的雜訊指標。

---

## 2. 欄位架構與預設配置規範 (Column Taxonomy)

為了避免初學者遭遇嚴重認知過載（Cognitive Overload），欄位選擇器應區分為「預設基礎欄位」與「進階選用欄位」：

| 欄位類別 | 推薦欄位項目 | 底層指標對齊與業務意義 | 預設狀態 |
| :--- | :--- | :--- | :--- |
| **基礎識別** | 股票代碼、股票名稱、目前股價、漲跌幅 | 基礎行情，數值旁嚴格配置顯式 `+`/`-` 與 ▲/▼ 圖標（[[多維視覺冗餘編碼 (Visual Redundancy)]]）。 | **固定常駐** |
| **存股與收益** | 現金殖利率、連續配息年數、下次除權息日、填息天數 | 存股族最核心關注指標，除權息前 14 天加註高亮提款提醒。 | **預設開啟** |
| **估值指標** | 本益比 (P/E)、股價淨值比 (P/B)、歷史 P/B 分位數 | 標註 P/B $< 1.0$ 之破淨標的，參閱 [[PBR 1倍破淨機制與資本收益性]]。 | **預設開啟** |
| **品質防雷 (進階)** | [[Piotroski F-Score 評分模型]] (0–9分)、[[Altman Z-Score 破產預警模型]] | 快速檢驗是否具備轉機動能，標記 $Z < 1.81$ 之破產警戒。 | 選用開啟 |
| **營運成長 (進階)** | 月營收 YoY、連增月數、近四季 EPS 年增率 | 配合 [[營運槓桿與產能利用率效應]] 檢視本業造血動能。 | 選用開啟 |
| **❌ 禁用/排除欄位** | **個股券資比、即時融資券增減、當沖比率** | 依據 [[金融數據降噪哲學 (Noise Elimination)]]，**嚴禁納入存股清單**，避免誘導散戶進行高摩擦短線博弈。 | **絕對排除** |

## 3. 前端互動流程與高齡防錯設計 (Error-Tolerant UX)

針對銀髮與退休長者手部震顫可能帶來的操作失誤，本頁面需落實以下工程防禦：

```
[使用者點擊清單項目上的「移除股票」按鈕]
                     │
                     ▼
[介面立即將該股票移出畫面，同時底部彈出 Undo Snackbar (浮動通知)]
┌─────────────────────────────────────────────────────────────┐
│  已將「2330 台積電」自觀察清單移除。         【 復原 (UNDO) 】 │
└─────────────────────────────────────────────────────────────┘
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
   點擊【復原】按鈕          倒數 5 秒超時
         │                       │
[立即還原該標的至清單中]    [正式提交狀態更新，持久化儲存]
```

- **高齡友善點擊熱區**：表格每列右側的「更多操作」選單或「移除」圖示按鈕，外層包覆之點擊熱區物理尺寸必須達到 **48x48px**，內部圖示保持 20x20px。詳見 [[高齡友善排版與觸控熱區規範]]。
- **純鍵盤與無障礙宣告**：表格每列支援鍵盤 Tab / Space 導航；刪除成功後，透過 `aria-live="polite"` 播報語音提示，確保視障與輔具使用者獲得即時反饋。

## 4. 跨裝置響應式架構 (RWD) 與狀態持久化

- **桌機 vs 手機斷點切換 (768px)**：
  - $\ge 768\text{px}$：渲染 `StockTable.vue`，支援水平自適應與欄位拖曳自訂寬度。
  - $< 768\text{px}$：自動切換為 `StockCard.vue` 卡片流。在 360px 視窗下，每張卡片採「左右兩欄」緊湊結構，左側為代號與名稱，右側為大字現價與殖利率，文字下限保持 16px。
- **持久化架構演進**：
  - **當前**：純本地記憶體 `useState`。
  - **短期改善**：封裝 `useLocalStorage`，確保使用者重新整理頁面後觀察名單不遺失。
  - **長期演進**：使用者登入後自動調用後端 REST API 進行雲端同步，並處理離線 IndexedDB 快取。
