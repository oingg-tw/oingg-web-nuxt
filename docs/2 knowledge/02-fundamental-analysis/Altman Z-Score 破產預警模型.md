# Altman Z-Score 破產預警模型

> Altman Z-Score 由紐約大學斯特恩商學院教授愛德華·奧特曼（Edward Altman）於 1968 年建立。該模型運用多變量判別分析（Multivariate Discriminant Analysis, MDA），將 5 項關鍵財務比率進行權重加權，精準預測企業在未來 1 至 2 年內發生財務破產或債務違約的機率，是基本面防雷與信用風險控管的業界標竿。

---

## 1. 製造業標準 Z-Score 權重公式

$Z = 1.2 X_1 + 1.4 X_2 + 3.3 X_3 + 0.6 X_4 + 0.999 X_5$

### 各因子財務比率與代表涵義：

| 變數因子 | 計算公式 | 經濟意涵與權重權值 |
| :--- | :--- | :--- |
| **$X_1$ (淨營運資金 / 總資產)** | $\frac{\text{流動資產} - \text{流動負債}}{\text{總資產}}$ | **短期流動性緩衝**。衡量企業短期內免於被流動性擠兌的週轉實力。 |
| **$X_2$ (保留盈餘 / 總資產)** | $\frac{\text{期末保留盈餘累計}}{\text{總資產}}$ | **長期累積獲利能力與企業壽命**。新創或長年虧損企業因分母擴大、分子為負，此值極低。 |
| **$X_3$ (EBIT / 總資產)** | $\frac{\text{息稅前利潤}}{\text{總資產}}$ | **資產本質生產力**（權重高達 3.3，影響最鉅）。衡量資產在排除稅賦與融資成本前的真實造血能力。 |
| **$X_4$ (股權市值 / 總負債)** | $\frac{\text{普通股與特別股市值}}{\text{流動負債} + \text{長期負債}}$ | **資本市場信任度與槓桿安全墊**。股價大跌或債務膨脹會劇烈壓低此項，顯示資產已無法覆蓋負債。 |
| **$X_5$ (營收 / 總資產)** | $\frac{\text{營業收入}}{\text{總資產}}$ | **總資產週轉率**。反映管理層利用資產產生銷貨收入的營運效率。 |

---

## 2. 判斷分區與臨界門檻

| Z-Score 區間 | 風險分類 | 實務違約機率與投資決策指引 |
| :--- | :--- | :--- |
| **$Z \ge 2.99$** | **安全區 (Safe Zone)** | 財務結構強健，流動性與獲利充足，未來 2 年內發生財務破產之統計機率極低（$<5\%$）。 |
| **$1.81 \le Z < 2.99$** | **灰色警戒區 (Grey Zone)** | 財務體質處於不穩定邊界。可能遭遇短期景氣逆風或負債增加，需密切監控現金流，列入觀察清單。 |
| **$Z < 1.81$** | **破產懸崖區 (Distress Zone)** | 破產機率極高（歷史驗證準確率達 80%–90%）。企業通常已面臨嚴重的償債困難與流動性枯竭，**絕對排除於投資組合之外**。 |

---

## 3. 非製造業與新興市場修正版 ($Z''$-Score)

針對非製造業、服務業或新興市場上市企業，Altman 推出了剔除資產週轉率 $X_5$（因服務業資產規模通常較小，易造成失真）的四因子修正模型：

$Z'' = 6.56 X_1 + 3.26 X_2 + 6.72 X_3 + 1.05 X_4$

- **安全區**：$Z'' > 2.60$
- **灰色區**：$1.10 \le Z'' \le 2.60$
- **破產區**：$Z'' < 1.10$
