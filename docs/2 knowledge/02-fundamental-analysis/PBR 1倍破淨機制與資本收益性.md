# PBR 1倍破淨機制與資本收益性

> 股價淨值比（P/B Ratio，PBR）跌破 1 倍（破淨），代表資本市場對該企業未來創造現金流能力的評價低於其帳面會計解散清算價值。從公司理財的理論模型出發，PBR 跌破 1 倍的根本原因，在於企業長期的股東權益報酬率（ROE）無法超越投資人的股權資本成本（$r_e$），陷入「低效留存資本 $\to$ 獲利能力進一步稀釋」的惡性折價循環。

---

## 1. PBR 的第一原理定價公式

根據股利折現模型（Gordon Growth Model），股票價格 $P$ 為：

$P = \frac{\text{BVPS} \times \text{ROE} \times (1 - b)}{r_e - g}$

其中：
- $\text{BVPS}$：每股淨值（Book Value Per Share）
- $b$：盈餘保留率（$1-b$ 為配息率）
- $g$：長期可持續成長率（$g = \text{ROE} \times b$）
- $r_e$：股權資本成本（Cost of Equity）

兩邊同除以每股淨值 $\text{BVPS}$，整理後可推導出 PBR 的結構方程式：

$\text{PBR} = \frac{P}{\text{BVPS}} = \frac{\text{ROE} - g}{r_e - g}$

---

## 2. 破淨機理：資本收益率與資本成本的對決

分析分子與分母的相對關係：

| 資本收益率條件 | 理論 PBR 水準 | 市場評價與定價機制 |
| :--- | :--- | :--- |
| $\text{ROE} > r_e$ | $\text{PBR} > 1.0$ 倍 | 企業獲利能力超越市場要求回報率，市場願意給予溢價。成長率 $g$ 越高，PBR 擴張幅度越大。 |
| $\text{ROE} = r_e$ | $\text{PBR} = 1.0$ 倍 | 企業恰好創造等同於資本成本的回報，市場以帳面淨值平價定價。 |
| $\text{ROE} < r_e$ | **$\text{PBR} < 1.0$ 倍** | **結構性跌破 1 倍**。每將 1 元盈餘保留於企業內部，市場僅視為價值小於 1 元的資產。成長率 $g$ 越高反而使 PBR 跌得更深（因擴張加速毀滅價值）。 |

### 日本與台灣市場實踐實證
- 台灣及日本資本市場中，股權資本成本 $r_e$ 一般座落於 **7% 至 8%** 區間。
- 若企業 ROE 長期低於 7%–8%（常見於無獲利增長動能之傳統代工廠、水泥、航運低谷），其 PBR 必然結構性沉淪於 0.6–0.8 倍。
- 若企業在此情境下仍不願提高配息率或實施庫藏股，而是持續將未分配盈餘累積為帳面現金，將進一步拉大股東權益分母，導致 ROE 進一步萎縮，引發長年「低估值陷阱（Value Trap）」。

---

## 3. 破淨企業的價值修復催化劑

要打破 PBR 1 倍折價詛咒，企業唯有採取積極的資本配置管理：

1. **大幅調高現金股利發放率**：將無法創造高報酬的閒置資金歸還股東，縮減淨值分母，強制拉高 ROE。
2. **在低於淨值時執行庫藏股註銷**：以低於 1 倍淨值的市價買回股票並註銷，數學上能即刻增厚剩餘股東的每股淨值與每股盈餘。
3. **終止無效益資本支出**：淘汰利差為負的產線，專注於提升 [[ROIC-WACC 價值創造模型]] 的正向利差。
