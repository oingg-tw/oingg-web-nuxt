# 特別股契約與評價模型

> 特別股（Preferred Stock）是兼具「股權（Equity）」與「債權（Debt）」特性的混合型金融工具。其定價不僅取決於發行企業的信用體質與固定股息率，更深度受到契約條款（清算優先權、累積性、參與分配權、發行人贖回權、投資人賣回權）與會計準則（IAS 32 / IFRS 9）的剛性約束。在評價上需依條款複雜度選用 DDM、OPM、PWERM 或晶格模型，並特別注意發行人贖回權引發的「負凸性（Negative Convexity）」風險。

---

## 1. 特別股核心契約條款解構

| 契約條款維度 | 條款機制與類型 | 對投資人之實質經濟影響 |
| :--- | :--- | :--- |
| **股息累積性 (Cumulative)** | 累積型 vs 非累積型 | 企業若當期虧損暫停發放特別股股息，累積型特別股必須在未來發放普通股股利前「全額補發」歷史欠款；非累積型則權利直接失效。 |
| **股息參與權 (Participating)** | 非參與型 vs 完全參與型 | 非參與型僅領取固定約定股息（如 4%）；完全參與型在領取固定股息後，若普通股每股分配額超過特定門檻，可按比例進一步參與超額盈餘分配。 |
| **清算優先倍數 (Liquidation Preference)** | 1x 至 3x 優先倍數 | 企業清算解散時，特別股持有人在普通股之前優先收回投資本金及累積股息之倍數保障。 |
| **贖回權 (Callable by Issuer)** | 發行人提前買回權 | 發行人有權在特定年份後（如發行滿 5 年或 7 年）按約定票面價格強制買回。限制了資本利得天花板。 |
| **賣回權 (Putable by Investor)** | 投資人賣回權 | 持有人有權在特定條件下要求發行人按約定價格買回。會計上常使特別股由權益轉化為負債。 |

## 2. 特別股主流評價模型選用矩陣

依據特別股是否具備轉換普通股權限以及企業發展階段，選用不同數學模型：

```
                    【特別股評價模型選用光譜】
                                 │
         ┌───────────────────────┴───────────────────────┐
         ▼                                               ▼
[無轉換權之傳統固定收益特別股]                  [含轉換權之複合型特別股 (Convertible)]
  │                                               │
  ├─► 股利折現模型 (DDM)                          ├─► 早期非上市企業 / 多輪創投：
  │   - 永續年金折現法: V = D / Kp                │   選擇權定價模型 (OPM Backsolve)
  │                                               │   - 設定清算優先斷點，以 Black-Scholes 計價
  └─► 最差殖利率模型 (Yield to Worst, YTW)       │
      - 比較持有至到期 (YTM) 與提前贖回 (YTC)    ├─► 臨近 IPO / 併購之成熟期企業：
        取其最低者作為定價保守基準                │   機率加權預期報酬法 (PWERM)
                                                  │
                                                  └─► 複雜美式行權 / 具多重贖回博弈：
                                                      Tsiveriotis-Fernandes (TF) 晶格模型
                                                      - 分拆純債部分 (信用利差折現)
                                                        與股權轉換部分 (無風險利率折現)
```

## 3. 負凸性（Negative Convexity）與流動性折價 (DLOM)

### 負凸性風險機制
- 一般傳統固定收益債券具備「正凸性」：利率下降時價格上漲幅度，大於利率上升時價格下跌幅度。
- **附發行人贖回權的特別股具備「負凸性」**：
  - 當市場利率大幅飆升時，價格隨存續期間大幅折價暴跌。
  - 當市場利率大幅下行時，由於發行人傾向以更低利率發行新股來「按票面價強制贖回舊股」，導致股價在接近贖回價時遭遇物理天花板（Call Price Compression），價格-殖利率曲線向下凹陷，投資人享受不到降息帶來的資本利得。

### 流動性缺乏折價 (DLOM)
針對非公開發行特別股，常運用 Chaffe 或 Finnerty 賣權定價模型估算流動性折價。由於特別股享有清算優先與股息累積保護，其 DLOM（通常為 10%–15%）必須合理低於普通股（25%–35%）。
