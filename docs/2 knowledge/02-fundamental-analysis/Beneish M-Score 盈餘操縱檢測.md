# Beneish M-Score 盈餘操縱檢測

> Beneish M-Score 由印第安納大學會計學教授梅索德·貝尼什（Messod Beneish）於 1999 年創立。該模型運用 Probit 迴歸，透過 8 項會計異常指標綜合計算單一數值，量化評估企業是否正在運用會計手法操縱、粉飾甚至虛構當期財務盈餘。最著名的案例是在安隆（Enron）弊案爆發前數年，該模型即準確亮出造假紅燈。

---

## 1. 八因子 Probit 迴歸權重公式

$M = -4.84 + 0.920 \times \text{DSRI} + 0.528 \times \text{GMI} + 0.404 \times \text{AQI} + 0.892 \times \text{SGI} + 0.115 \times \text{DEPI} - 0.172 \times \text{SGAI} + 4.037 \times \text{TATA} + 0.0327 \times \text{LVGI}$

### 八項關鍵指標之會計意義

| 變數代號 | 指標名稱與計算方式 | 異常閾值 | 會計粉飾手法與偵測目的 |
| :--- | :--- | :--- | :--- |
| **DSRI** | 應收帳款週轉天數指數 $(\text{DSO}_t / \text{DSO}_{t-1})$ | $> 1.0$ | **塞貨與虛構營收**。應收帳款增長速度遠超營收，代表貨款無法收回，甚至虛構銷貨。 |
| **GMI** | 毛利率惡化指數 $(\text{Margin}_{t-1} / \text{Margin}_t)$ | $> 1.0$ | **本業獲利承壓動機**。前期毛利率高於當期，顯示獲利惡化，管理層有強烈動機進行盈餘操縱。 |
| **AQI** | 資產品質指數 $(\text{非流動且非PP&E資產佔比}_t / \text{前期比})$ | $> 1.0$ | **費用資本化**。將原本應列於損益表的研發、行銷或營運費用，藏入其他資產或無形資產中遞延。 |
| **SGI** | 營收成長指數 $(\text{營收}_t / \text{營收}_{t-1})$ | 異常飆高 | **成長放緩焦慮**。高速成長企業一旦動能放緩，極易鋌而走險虛增營收以維持市場估值。 |
| **DEPI** | 折舊放緩指數 $(\text{折舊率}_{t-1} / \text{折舊率}_t)$ | $> 1.0$ | **拉長攤銷年限**。管理層透過延長折舊資產耐用年限或調降折舊率，人為減少當期營業費用。 |
| **SGAI** | 推銷與管理費用指數 $(\text{SGA費用率}_t / \text{前期比})$ | $> 1.0$ | **行政效率惡化**。管理費用率上升代表企業失控，催生美化損益表的誘因。 |
| **LVGI** | 財務槓桿指數 $(\text{負債率}_t / \text{前期比})$ | $> 1.0$ | **債務合約壓力**。負債比攀升促使管理層粉飾財報，以避免觸發銀行聯貸違約條款。 |
| **TATA** | 總應計項目與總資產比 $(\frac{\text{淨利} - \text{營業現金流 CFO}}{\text{總資產}})$ | 顯著為正 | **會計獲利與現金脫節**。權重高達 4.037，最直接揭露沒有現金流入支撐的「純紙上富貴」。 |

## 2. 判斷標準與臨界值

| M-Score 數值區間 | 統計判定分類 | 實務處置措施 |
| :--- | :--- | :--- |
| **$M \le -1.78$** | **正常安全 (Unlikely Manipulator)** | 數值越負（如 $-2.5, -3.0$），財務數據越健康，存在盈餘操縱的機率極低。 |
| **$M > -1.78$** | **高度警訊 (Likely Manipulator)** | 數值偏向正值（如 $-1.2, 0.5$），顯示財報存在高度盈餘美化或做假跡象，**應立即排除並啟動法證審查**。 |

## 3. 在量化排雷系統中的戰略地位

在建立存股與退休投資池時，防守的重要性遠大於進攻：
- 結合 [[Altman Z-Score 破產預警模型]]，形成雙重安全鎖（M-Score 查舞弊，Z-Score 查違約）。
- 特別適用於跨國治理較薄弱的公司，如 [[KY 股法證會計檢驗架構]] 中提到的第一上市櫃公司。
