# Piotroski F-Score 評分模型

> Piotroski F-Score 由史丹佛大學會計學教授約瑟夫·皮爾托斯基（Joseph Piotroski）於 2000 年提出。該模型專門用於從「低股價淨值比（低 PBR）」的價值股清單中，透過財務報表的 9 項二元檢驗指標（符合得 1 分，不符合得 0 分），精確篩選出財務體質實質好轉、具備轉機動能的優質企業，徹底排除陷入長期衰退的「價值陷阱（Value Trap）」。

---

## 1. 九大二元評分指標全景解析

F-Score 總分為 0 至 9 分，涵蓋三大財務健康構面：

| 構面名稱 | 評分指標項目 | 判定規則（得 1 分條件） | 會計檢驗意義與防禦目的 |
| :--- | :--- | :--- | :--- |
| **一、獲利能力 (Profitability)** | **1. ROA** | 當期淨利 / 總資產 $> 0$ | 確保本期資產產生實質正向收益。 |
| | **2. CFO** | 營業活動現金流量 $> 0$ | 確保本業具備自發性產生現金的能力。 |
| | **3. $\Delta \text{ROA}$** | 當期 ROA $>$ 前期 ROA | 獲利能力具備向上的正向動能。 |
| | **4. Accrual (應計項)** | **$\text{CFO} > \text{當期淨利}$** | **最核心會計防禦**。排除以應收帳款膨脹或費用資本化所堆砌出的虛假會計利潤。 |
| **二、財務槓桿與流動性 (Leverage & Liquidity)** | **5. $\Delta \text{Leverage}$** | 當期長期負債比率 $<$ 前期比率 | 長期債務負擔減輕，降低財務違約風險。 |
| | **6. $\Delta \text{Liquidity}$** | 當期流動比率 $>$ 前期比率 | 短期償債緩衝墊厚度增加。 |
| | **7. 股本稀釋** | 直近期內**無發行新股**（無現金增資） | 避免每股盈餘與權益遭到稀釋，代表企業資金能自給自足。 |
| **三、營運效率 (Operating Efficiency)** | **8. $\Delta \text{Margin}$** | 當期營業毛利率 $>$ 前期毛利率 | 代表企業在供應鏈中具備成本控制力或定價轉嫁權（抵抗 [[PPI-CPI 剪刀差與毛利率敏感度]]）。 |
| | **9. $\Delta \text{Turnover}$** | 當期總資產週轉率 $>$ 前期週轉率 | 每單位資產創造營收的生產力改善，資產運用效率提高。 |

---

## 2. 評分等級劃分與投資決策

- **8 – 9 分（高強韌優質股）**：基本面全面轉強，各項營運效率顯著改善。學術實證顯示，買進低 PBR 且 F-Score 達 8–9 分的組合，長期年化超額報酬顯著超越大盤。
- **4 – 7 分（中性持平區）**：多數普通企業座落於此，需搭配其他質化護城河指標深入分析。
- **0 – 3 分（財務脆弱地雷股）**：伴隨營業現金流枯竭、高槓桿與應收帳款異常，即使股價跌到看似便宜的歷史低點，極大概率為即將暴跌的「價值陷阱」，應立即列入負面排除清單。

## 3. 與其他量化模型之串聯工作流

在專業量化選股管線中，F-Score 通常作為第二道「品質與動能過濾網」：

```
[初選池] 低 PBR 價值股 / 存股池
    │
    ▼ 階段一：破產與舞弊排除
    剔除 [[Altman Z-Score 破產預警模型]] < 1.81 及 [[Beneish M-Score 盈餘操縱檢測]] > -1.78 之危險股
    │
    ▼ 階段二：體質轉強篩選
    挑選 【Piotroski F-Score】 >= 7 分之優質動能股
    │
    ▼ 階段三：長期價值創造驗證
    驗證 [[ROIC-WACC 價值創造模型]] 之正利差持續性
```
