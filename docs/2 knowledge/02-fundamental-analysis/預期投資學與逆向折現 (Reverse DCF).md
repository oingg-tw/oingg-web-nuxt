# 預期投資學與逆向折現 (Reverse DCF)

> 預期投資學（Expectations Investing）由邁克爾·莫布森（Michael Mauboussin）與阿爾弗雷德·拉帕波特（Alfred Rappaport）奠基。傳統 DCF 試圖透過預測未來 10 年的現金流來猜測股價，極易受主觀假設操弄；「逆向折現（Reverse DCF）」反其道而行，將「當前市場股價」視為已知數，反向工程推導出市場隱含的定價預期（PIE: Price-Implied Expectations），進而評估市場是過度樂觀還是過度悲觀。

---

## 1. 傳統 DCF 的宿疾 vs 逆向 DCF 的思維反轉

- **傳統 DCF 的致命盲點**：DCF 對終端價值（Terminal Value）與折現率（WACC）極端敏感。分析師只需將成長率調高 1% 或將 WACC 下調 0.5%，估值結果就能瞬間跳升 30%–50%，淪為「拿結論找依據」的數字遊戲。
- **逆向 DCF 的工程邏輯**：
  
  $\text{當前股價 } P_0 = \sum_{t=1}^{N} \frac{\text{預估 FCF}_t}{(1 + \text{WACC})^t} + \frac{\text{終端價值 } \text{TV}_N}{(1 + \text{WACC})^N}$
  
  我們將 $P_0$ 視為輸入變數，保持合理的 WACC，**反向求解市場隱含的 FCF 年複合成長率（CAGR）或營收利潤率預期**。

---

## 2. 逆向推導三部曲工作流

```
[步驟一：輸入市場現價與 WACC]
將當前股價 P0、流通股數與客觀 WACC 輸入模型
      │
      ▼
[步驟二：反向求解市場隱含預期 (PIE)]
計算要合理化當前市值，企業未來 5~10 年必須達成：
- 營收年複合成長率 (CAGR) 為何？
- 營業利益率與自由現金流轉換率為何？
- 投資資本回報率 (ROIC) 需達到多高？
      │
      ▼
[步驟三：歷史基準率 (Base Rates) 壓力測試]
將求解出的 PIE 與產業歷史常態、企業過去能力及同業上限交叉審查：
- 市場隱含年增 35%：歷史上同等體量企業達成機率是多少？（例如僅 2%）
- 若達成機率極低 ──► 屬於市場「過度定價/泡沫」，具備巨大下行風險
- 若市場僅隱含年增 3%，但產業新動能清晰 ──► 存在顯著「預期差（Expectation Gap）」，買進具備厚實安全邊際
```

---

## 3. 「後照鏡」與「擋風玻璃」的有機融合

基本面投資絕非單純依賴歷史財報：
- **歷史財務數據（後照鏡）**：由 [[常態化獲利與財報回溯年限]] 與 [[ROIC-WACC 價值創造模型]] 提供客觀的「歷史基準率（Base Rates）」，告訴我們企業的極限在哪裡。
- **逆向 DCF（擋風玻璃）**：清晰描繪出市場當前正在「押注什麼樣的故事」。
- **超額報酬的本質**：並非買進好公司，而是**捕捉「市場共識預期」與「未來客觀現實」之間的巨大正向落差**。
