# Merchant of Record (MoR) 跨境金流選型

> 在建置軟體線上付費與訂閱金流時，技術架構選型的核心分水嶺在於：究竟應選擇傳統的「支付服務商（PSP, Payment Service Provider，如 Stripe）」自建稅務系統，還是採用「記錄商戶（MoR, Merchant of Record，如 Paddle、Lemon Squeezy）」。MoR 在法律層面作為交易的「合法轉售方（Reseller）」，直接承擔全球超過 200 個法區的數位服務稅（Sales Tax / VAT / GST）申報、代扣代繳與審計責任，是中小型軟體出海避開天價合規罰款的最佳解法。

---

## 1. PSP (Stripe) vs MoR (Paddle / Lemon Squeezy) 底層法律與交易流向對比

```
【傳統 PSP 模式 (Stripe)】
終端消費者 ────購買軟體並付款────► 您的企業 (作為唯一法律責任主體)
                                       │
                                       ├─► 需自行在美國 40+ 州註冊 Sales Tax
                                       ├─► 需自行在歐盟註冊 VAT OSS 申報繳稅
                                       └─► 需自聘會計師面對跨國稅局查稅審計

【記錄商戶 MoR 模式 (Paddle / Lemon Squeezy)】
終端消費者 ────付款購買軟體────► 【MoR 記錄商戶 (法定銷售實體)】
                                       │
                                       ├─► MoR 依法向消費者開立當地合規發票
                                       ├─► MoR 全自動承擔全球 200+ 稅區申報與繳稅
                                       ▼
                              扣除手續費後，將純利潤撥付給【您的企業】(B2B 單一申報)
```

## 2. 標稱費率與真實綜合交易成本對決

評估金流成本時，切忌只看官方宣傳的牌面手續費：

| 金流維度構面 | Stripe (純 PSP 自建模式) | Paddle / Lemon Squeezy (MoR 模式) | 實務財務分析與優劣結論 |
| :--- | :--- | :--- | :--- |
| **官方標稱牌面費率** | 2.9% + $0.30 | 5.0% + $0.50 | 表面上看 Stripe 手續費便宜近一半。 |
| **隱性交易加價項目** | - 國際跨境卡處理費：+1.5%<br>- 跨國貨幣換匯手續費：+1.0%<br>- Stripe Tax 稅務計算引擎：+0.5% | 費率已包含跨境卡處理，換匯費約 2%–3%。 | 在面對跨國消費者時，Stripe 的實際交易手續費已攀升至 **5.4% 至 5.9%**。 |
| **稅務合規外部成本** | **極高**。需購買 TaxJar 等合規工具（年費數千美元），且需聘請外部會計師處理跨國申報，每年審計維護成本動輒 **$20,000 – $50,000 美元**。 | **完全為零 ($0)**。<br>全數由 MoR 平台的全球法務與會計團隊統一吸收，平台承擔全額審計法律責任。 | **關鍵轉折點**：年營收 50 萬美元以下時，MoR 的總財務支出遠低於自建 Stripe + 會計師成本。 |
| **爭議款 (Chargeback) 處理** | 每筆收取 $15 處理費，需自行撰寫抗辯信並提交證據。 | 每筆約 $15，由 MoR 平台的風控與律師團隊統一出面抗辯。 | 降低運營團隊的行政摩擦。 |
| **資金結算提領週期** | **T+2 滾動撥款**（資金流動性極高）。 | 雙週結算或次月 15 日月結（資金週轉需預留緩衝）。 | Stripe 在現金流即時性上略勝一籌。 |

## 3. 企業生命週期選型決策模型

- **階段一：年營收 $< 50$ 萬美元（冷啟動與出海驗證期）**：
  - **唯一推薦 MoR（Paddle / Lemon Squeezy）**。
  - 將所有跨國稅務風險、發票格式規範、歐盟 GDPR 與各州經濟聯結（Economic Nexus）全額外包，團隊 100% 專注於產品功能迭代與用戶增長。
- **階段二：年營收 $> 100$ 萬至 300 萬美元（規模化擴張期）**：
  - 核心用戶若已高度集中在少數特定市場（例如 80% 來自美國與台灣本土）。
  - 此時節省下來的 2% 手續費差額足以覆蓋自建財務團隊與合規工具成本，可評估切回 Stripe 自建架構以最大化毛利。
