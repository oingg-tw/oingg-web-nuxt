# Guyton-Klinger 動態提領護欄模型

> Guyton-Klinger 護欄模型（Guyton-Klinger Guardrails）由財務規劃師喬納森·蓋頓（Jonathan Guyton）與威廉·克林格（William Klinger）於 2004–2006 年提出。該模型突破了威廉·班根（William Bengen）傳統「4% 固定實質提領法則」的剛性死板缺陷，透過「資本保全規則（下限）」、「繁榮規則（上限）」與「通膨跳過規則」，在市場繁榮時適度犒賞生活、在市場蕭條時微調支出，將退休初期的安全提領率（SWR）自 4.0% 大幅提升至 **5.2% – 5.6%**。

---

## 1. Bengen 4% 法則的局限性 vs 動態護欄優勢

- **4% 法則的僵固性**：假定期初提領總資產的 4%，未來每年無論股市暴跌或暴漲，提領金額皆「強制依通膨率向上調升」。
  - 在大熊市（如 1970 年代停滯性通膨）中，強制調升提領金額會加速本金耗盡，引發 [[序列報酬風險 (Sequence of Returns Risk)]]。
  - 在大牛市中，資產可能在退休末期暴增數倍，導致投資人過度節儉、未能在有生之年享受財富。
- **Guyton-Klinger 護欄思維**：現實中的人類具備彈性支出調節能力。只要在市場極端偏離時，承諾做 **10% 的微調支出**，即可大幅釋放初期安全提領金額。

---

## 2. Guyton-Klinger 四大決策護欄規則

```
當期提領率 = (當期生活費支出 / 當期投資組合總市值)
                      ▲
                      │
     [上限護欄：當期提領率超出期初 +20%] ──► 觸發【資本保全規則】：提領金額減少 10%
                      │
     [中性安全區間] ───────────────────────► 提領金額依正常 CPI 通膨調整
                      │
     [下限護欄：當期提領率低於期初 -20%] ──► 觸發【繁榮分享規則】：提領金額增加 10%
```

| 護欄規則名稱 | 觸發量化條件 | 執行調控機制與財務效果 |
| :--- | :--- | :--- |
| **一、資本保全規則 (Capital Preservation Rule)** | 當期提領率相較期初基準提領率**上升超過 20%**（例如期初 5.0%，當期因市值大跌使提領率達 $6.0\%$）。 | **提領金額主動調降 10%**。<br>實施於退休前 15 年，主動縮減支出以減輕資產抽血壓力，徹底阻斷資產歸零。 |
| **二、繁榮分享規則 (Prosperity Rule)** | 當期提領率相較期初基準提領率**下降超過 20%**（例如期初 5.0%，當期因牛市使提領率降至 $4.0\%$）。 | **提領金額主動調升 10%**。<br>讓退休者在身體健康時分享市場成長紅利，避免資產無效沉澱。 |
| **三、通膨跳過規則 (Inflation Rule)** | 投資組合上一年度的**名目總報酬率為負數**。 | **凍結當年度的通膨加成**。<br>當期生活費不依 CPI 向上調增，維持與上一年度相同金額，避免在虧損年擴大提領額。 |
| **四、投資組合重整規則 (Portfolio Management Rule)** | 每年產生提領現金時。 | **從過去一年漲幅最大的資產類別提領**，跌破原始配置比例的資產不提領，等同內建「逢高出脫、自動再平衡」機制。 |

## 3. Vanguard 動態支出模型對照

除了 Guyton-Klinger，先鋒集團（Vanguard）亦提出動態支出上限與下限模型（Vanguard Dynamic Spending）：
- 每年提領金額以「前一年度總資產的一定比率（如 4%–5%）」為基準。
- 設定每年支出名目調整的「天花板（上限 +5%）」與「地板（下限 -2.5%）」。
- 該模型同樣能有效平滑生活開銷，同時給予資產充裕的抗跌彈性。
