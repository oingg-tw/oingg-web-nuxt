# PPI-CPI 剪刀差與毛利率敏感度

> 「PPI－CPI 剪刀差」是指生產者物價指數（PPI，代表上游出廠成本）年增率減去消費者物價指數（CPI，代表終端售價）年增率的動態差額。該差額量化了價格壓力在產業鏈上中下游傳導的順暢度，是預測中下游製造業與零售消費業營業毛利率（Gross Margin）擴張或萎縮的先導性指標。

---

## 1. 剪刀差的數理定義與利潤傳導機理

$\Delta_{\text{Scissors}} = \text{PPI YoY} - \text{CPI YoY}$

在製造與加工產業鏈中，企業損益表毛利率取決於平均售價（ASP）與銷貨成本（COGS）的相對變化：

$\text{毛利率 (Gross Margin)} = \frac{\text{ASP} - \text{單位 COGS}}{\text{ASP}} = 1 - \frac{\text{單位 COGS}}{\text{ASP}}$

### 兩種剪刀差狀態的實質經濟意涵

| 剪刀差狀態 | 數值特徵 | 實體經濟運作機理 | 中下游企業財務表現 |
| :--- | :--- | :--- | :--- |
| **正向剪刀差擴大 (Positive Spread)** | $\text{PPI} \gg \text{CPI}$ ($\Delta > 0$) | 原物料、原油、航運或核心零組件等上游成本暴漲，但終端消費需求疲弱或競爭激烈，廠商無法完全轉嫁成本。 | **中下游毛利率嚴重受壓**。出現「營收隨通膨名目虛增，但毛利與營業利益大幅萎縮」的「利潤貧血」現象。上游採掘業受惠。 |
| **剪刀差收窄乃至轉負 (Negative Spread)** | $\text{PPI} \ll \text{CPI}$ ($\Delta < 0$) | 上游原物料價格大幅回落出清，但終端產品價格具備向下剛性（黏性）或終端需求復甦，下游售價維持高檔。 | **中下游毛利率結構性爆發**。單位成本驟降帶來獲利彈性，是製造業盈餘超預期上修的主要驅動力。 |

## 2. 產業定價權（Pricing Power）的防禦濾網

面對正向剪刀差的衝擊，並非所有企業都會遭遇毛利率受損。巴菲特所強調的「經濟護城河」在此展現出量化分水嶺：

- **缺乏護城河的代工廠（純 Price Taker）**：
  - 產品同質化高，轉換成本為零。
  - 上游原物料每上漲 10%，若客戶只允許調漲 3%，剩餘 7% 差額只能由自身營業利益硬吞，營業毛利率常直接腰斬。
- **具備定價權的護城河企業（Price Maker）**：
  - 具備專利壁壘、高轉換成本或強大品牌溢價。
  - 能在合約中配置「原料價格聯動條款」或直接調漲牌價，將成本全額轉嫁給終端客戶，甚至在成本回落時維持高價，享受剪刀差反轉後的超額暴利。

## 3. 基本面分析與選股關聯應用

- **營收真實性驗證**：觀察企業營收成長時，必須結合 PPI 與 CPI 交叉比對，排除純粹因原物料名目漲價帶來的「虛胖營收」，搭配 [[DuPont 杜邦分析三因子拆解]] 檢視淨利率是否實質提升。
- **美林時鐘對應**：剪刀差正向極值通常發生在 [[美林投資時鐘資產輪動模型]] 的「過熱期」與「滯脹期」交界，是拋售無定價權中下游股票的關鍵窗口。
- **量化品質指標**：在 [[Piotroski F-Score 評分模型]] 中，第 8 項「毛利率前期比改善（$\Delta \text{Gross Margin} > 0$）」是評估企業是否戰勝剪刀差壓迫的剛性濾網。
