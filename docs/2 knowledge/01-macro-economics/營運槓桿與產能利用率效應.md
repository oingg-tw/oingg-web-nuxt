# 營運槓桿與產能利用率效應

> 營運槓桿（Operating Leverage）衡量企業固定營運成本在整體營運成本結構中的佔比，決定了營業利益（Operating Income）對營收變動的敏感度倍數。在重資本與高固定成本產業中，當實質經濟成長帶動產能利用率越過損益兩平點時，將釋放出巨大的「正向營運槓桿」，使獲利呈現幾何級數爆發；反之在景氣下行期則會觸發破壞性的獲利雪崩。

---

## 1. 數理模型與營運槓桿度（DOL）

企業營運成本劃分為「固定成本（FC，如廠房折舊、專利攤銷、核心薪資）」與「變動成本（VC，如原材料、計件工資、水電瓦斯）」：

$\text{營業利益 (EBIT)} = Q(P - V) - F$

其中：
- $Q$：生產或銷售數量
- $P$：產品單價
- $V$：單位變動成本
- $F$：固定總成本

### 營運槓桿度（Degree of Operating Leverage, DOL）定義：

$\text{DOL} = \frac{\% \Delta \text{EBIT}}{\% \Delta \text{營收}} = \frac{Q(P - V)}{Q(P - V) - F} = \frac{\text{邊際貢獻}}{\text{EBIT}}$

- 當企業固定成本 $F$ 極高時，分母 $(Q(P-V) - F)$ 在損益兩平點附近極小，$\text{DOL}$ 數值極高。
- 此時營收僅需微幅成長 5%，營業利益即可飆升 30%–50%。

---

## 2. 產能利用率跨越損益兩平點的非線性爆發

以半導體晶圓代工（如台積電、聯電）或面板、封測業為例，巨額資本支出帶來每年數百億至上千億的折舊費用（固定成本）：

```
營業利潤 (EBIT)
    ▲
    │                               / (正向營運槓桿爆發期)
    │                              /
    │                             /  DOL 逐漸收斂，但利潤絕對值極大
    │                            /
────┼───────────────────────────/──────► 產能利用率 (%)
    │                          / 損益兩平點 (Break-even, 通常 70%~75%)
    │                         /
    │  (負向營運槓桿折磨期)   /
    │  折舊固定提列，利潤急劇虧損
```

- **稼動率（產能利用率）低於 70%**：每片晶圓分攤的折舊過高，營運處於微利甚至虧損。
- **稼動率從 75% 攀升至 95% 滿載**：每增加一單位的產出，邊際成本僅有少量的變動電費與材料費，幾乎每一元新增營收都能全額沉澱為營業利益，推動每股盈餘（EPS）呈現爆發性成長。

## 3. 雙向利刃與週期性風險

營運槓桿是典型「以波動換爆發力」的雙向機制：

| 景氣階段 | 營運槓桿方向 | 企業財務特徵 | 投資決策指引 |
| :--- | :--- | :--- | :--- |
| **景氣復甦/上行期** | **正向槓桿** | 訂單回流帶動產能利用率躍升，營業利益率大幅超前營收增長。 | 配合 [[戴維斯雙擊與雙殺效應]]，此時是重資本週期股報酬率最豐厚的黃金時期。 |
| **景氣收縮/衰退期** | **負向槓桿** | 終端需求凍結，工廠稼動率跌破損益兩平點，固定折舊持續提列，利潤腰斬或轉虧。 | 需提前檢驗 [[基本面財報觀察年限分析]]，避免在景氣高峰因低本益比誤買「週期頂峰假象股」。 |
