# 實質利率與資產定價折現機制

> 實質利率（Real Interest Rate）代表扣除通貨膨脹預期後的實質資金成本，是資本市場無風險資產定價與折現率（WACC）的物理底座。實質利率的微小波動，透過現金流量折現模型（DCF）對不同存續期間（Duration）的金融資產產生高度非對稱的估值壓縮或擴張效應。

---

## 1. 費雪方程式與資產折現底層架構

依據費雪方程式（Fisher Equation），名目利率 $i$ 與實質利率 $r$ 及預期通膨率 $\pi^e$ 的關係為：

$1 + i = (1 + r)(1 + \pi^e) \quad \implies \quad r \approx i - \pi^e$

### 現金流量折現模型（DCF）之傳導
任何權益資產或企業內在價值 $V_0$，為未來所有預期自由現金流（FCF）之折現現值加總：

$V_0 = \sum_{t=1}^{\infty} \frac{\text{FCF}_t}{(1 + \text{WACC})^t}$

其中加權平均資金成本（WACC）中，股權資本成本 $r_e$ 依 CAPM 計算：

$r_e = R_f + \beta \times \text{ERP}$

當央行調整貨幣政策推動實質利率 $R_f$ 上升時，WACC 折現率將被等量或超額墊高。

## 2. 久期效應（Duration Effect）與資產類別敏感度

折現率上升對各類型資產的價格彈性，本質上取決於該資產現金流的**有效存續期間（Macauley / Modified Duration）**：

| 資產類別 | 現金流時間分布特性 | 存續期間 (Duration) | 實質利率上升時之估值衝擊幅度 |
| :--- | :--- | :--- | :--- |
| **遠期高成長股 (Long-Duration Growth)** | 當期獲利微薄，高額利潤寄託於 5–10 年後的終端價值（Terminal Value） | 極長 ($>15$ 年) | **極重度殺戮**。分母複利折現因子 $(1+r)^t$ 在 $t$ 較大時產生指數級縮水，引發估值倍數腰斬。 |
| **成熟高配息價值股 (Short-Duration Value)** | 當期即有龐大且穩定的自由現金流與現金股利返還 | 較短 ($<5$ 年) | **輕度至中度受挫**。近端現金流受折現率上調的幾何稀釋效應極小，且若具備通膨定價權，分子端現金流能同步擴張。 |
| **長天期公債 (Long-Term Treasuries)** | 固定票息，本金於 20–30 年後償還 | 極長 ($15$ 至 $20$ 年) | **價格劇烈下跌**。利率每上升 100 bps，價格跌幅約等於有效存續期間百分比（約 15%–20%）。 |
| **超短期現金/貨幣市場 (MMF)** | 30–90 天內即到期重新定價 | 極短 ($<0.25$ 年) | **受惠**。實質現金流立即享受升息帶來的更高再投資報酬。 |

## 3. 實質利率轉向時的跨資產聯動

- **實質利率下行（寬鬆週期）**：
  - 推動遠期成長股估值倍數擴張，觸發 [[戴維斯雙擊與雙殺效應]] 的估值擴張端。
  - 對應 [[美林投資時鐘資產輪動模型]] 的復甦期與衰退後期。
- **實質利率飆升（緊縮週期）**：
  - 壓抑股票市場的整體本益比（P/E），引發股票與長天期債券同步下挫。
  - 企業債務再融資成本驟增，容易暴露體質脆弱企業，需透過 [[Altman Z-Score 破產預警模型]] 與 [[Piotroski F-Score 評分模型]] 進行篩選防護。
