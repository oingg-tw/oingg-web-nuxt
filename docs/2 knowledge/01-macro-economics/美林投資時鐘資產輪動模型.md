# 美林投資時鐘資產輪動模型

> 美林投資時鐘（Merrill Lynch Investment Clock）是由美林證券於 2004 年提出的經典由上而下（Top-Down）資產配置架構。該模型將實體經濟運作抽象為「經濟成長趨勢（產出缺口）」與「通貨膨脹方向」兩大核心維度，劃分為復甦、過熱、滯脹、衰退四個象限，精闢闡釋了跨週期大類資產（股票、債券、大宗商品、現金）與產業板塊的輪動規律。

---

## 1. 美林時鐘四象限與資產輪動全景

```
                 ▲ 經濟成長 (Growth)
                 │
      【復甦期 (Recovery)】 │     【過熱期 (Overheat)】
      - 成長加速 / 通膨低迷 │     - 成長見頂 / 通膨高企
      - 最優資產：股票 (Equities)  │     - 最優資產：大宗商品 (Commodities)
      - 領跑：半導體、可選消費   │     - 領跑：能源、採掘、原物料
─────────────────┼────────────────────────► 通膨 (Inflation)
      【衰退期 (Recession)】│     【滯脹期 (Stagflation)】
      - 成長收縮 / 通膨走低 │     - 成長失速 / 通膨僵固
      - 最優資產：債券 (Bonds)    │     - 最優資產：現金 (Cash)
      - 領跑：公用事業、高股息   │     - 領跑：必需消費、醫療防禦
                 │
```

## 2. 四大週期象限深度特徵與傳導機制

| 象限名稱 | 總經宏觀特徵 | 貨幣與利率政策 | 最佳資產與獲利驅動邏輯 | 權益資產內部領軍類股 |
| :--- | :--- | :--- | :--- | :--- |
| **復甦期 (Recovery)** | 產出缺口閉合中，GDP 增長回升，產能利用率築底，物價維持低位。 | 寬鬆低利率，流動性充沛。折現率處於低檔。 | **股票 (Equities)**<br>低資金成本加上補庫存需求，獲利與估值同步回升，迎來 [[戴維斯雙擊與雙殺效應]] 的雙擊期。 | 科技半導體、消費性電子、工業自動化、非必需消費 |
| **過熱期 (Overheat)** | 產能利用率見頂，勞動市場過熱，工資與原物料價格大幅攀升。 | 央行啟動升息抗通膨，推高實質利率與無風險利率。 | **大宗商品 (Commodities)**<br>實體供需瓶頸推升原油、銅等價格；股票內部估值倍數承壓，但能源原物料板塊獲利創新高。 | 能源石油、基本金屬、化學原物料、受惠升息之銀行業 |
| **滯脹期 (Stagflation)** | 經濟成長失速衰退，但供應鏈瓶頸或地緣政治使通膨黏性僵固。 | 政策進退維谷（抗通膨需升息，救經濟需降息），陷入流動性收縮。 | **現金 (Cash)**<br>股債雙殺，實質回報全面承壓。超短天期貨幣市場基金（MMF）是控制波動度與保全本金的最佳避風港。 | 醫療保健、公用事業、民生必需食品（剛性抗跌防禦股） |
| **衰退期 (Recession)** | 實體總需求系統性萎縮，企業大裁員與削價清庫存，通膨迅速崩解。 | 央行啟動緊急連續降息，釋放寬鬆救市。 | **政府公債 (Bonds)**<br>基準利率斷崖式下墜，中長天期公債享受巨大的資本利得空間；衰退末期優質權益資產完成估值出清。 | 傳統公用事業、高信評電信股、長天期國債 ETF |

## 3. 現代金融演變：「美林電風扇」與應對心法

在過去的二十年間，受全球央行超常規量化寬鬆（QE）、地緣政治斷鏈以及突發公共衛生事件衝擊，景氣循環的轉移節奏大幅加快，甚至出現跳過某些象限的「美林電風扇」現象（如 2020 年數月內由衰退直接轉向極度寬鬆與通膨）。

### 投資應用指引
- **不可機械式計時**：美林時鐘是「羅盤」而非「碼表」，重點在於判讀當下處於何種成長與通膨坐標，而非假設每隔兩年自動逆時針轉一格。
- **結合微觀護城河防禦**：純粹由上而下的板塊輪動容易陷入過度擇時交易損耗（DALBAR 實證散戶年化落後大盤 3.5%–4.8%），必須搭配 [[總經與個股基本面分析]] 的 80/20 策略：80% 部位順應週期大方向，20% 部位長線持有具備強大護城河的卓越企業。
