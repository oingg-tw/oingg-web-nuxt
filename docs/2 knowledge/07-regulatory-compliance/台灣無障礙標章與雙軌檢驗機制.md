# 台灣無障礙標章與雙軌檢驗機制

> 台灣官方推行的網站無障礙認證體系，主管機關歷經研考會、國發會、NCC，現由數位發展部（MODA）全面接掌，其最新法律基準為《網站無障礙規範2021》（110.07 版）。該規範全面對接國際 W3C 之 WCAG 2.1 AA 標準，要求涵蓋公部門、教育單位及廣泛的金融公共系統（網銀、證券下單介面）。認證審查採「機器自動檢測（FreeGo 單機工具）＋ 人工專家實測」之「雙軌檢驗機制」，並以嚴謹的十碼代碼體系進行缺失判定。

---

## 1. 規範法源與四大核心原則 (POUR)

台灣規範全面繼承 WCAG 的 POUR 四大基石，區分為 A 級、AA 級（一般公共服務強制基準）與 AAA 級：

```
+─────────────────────────────────────────────────────────────+
|           【數位發展部網站無障礙規範 POUR 四大原則】           |
+─────────────────────────────────────────────────────────────+
  ├─► [P] 感知性 (Perceivable)   ── 文字替代、字幕、對比度 4.5:1、色彩非唯一媒介
  ├─► [O] 可操作性 (Operable)    ── 純鍵盤可遊歷、無鍵盤陷阱、足夠閱讀時間、防癲癇
  ├─► [U] 可理解性 (Understandable) ── 頁面語言標記、導航一致性、表單錯誤文字指引
  └─► [R] 穩健性 (Robust)        ── HTML 語法規範、相容各類螢幕報讀輔具 (NVDA/JAWS)
```

## 2. 檢驗代碼體系：C 類機器碼 vs E 類人工碼

台灣規範採用專屬的「十碼檢驗代碼」（例如 `XX3141099E`），其英文字母後綴決定了測試路徑：

| 檢驗碼後綴類型 | 檢驗方式與工具 | 典型評量項目範例 | 稽核標準與通過條件 |
| :--- | :--- | :--- | :--- |
| **C 類代碼 (Check 機器測)** | 由官方 **FreeGo 單機自動化檢測工具** 批量爬取掃描。 | - `img` 標籤缺少 `alt` 屬性。<br>- 頁面缺少 `<html lang="zh-Hant">`。<br>- 表單控制項缺少 `id` 或未關聯 `<label>`。<br>- 顏色純文字對比度低於 4.5:1。 | **零容忍標準**。<br>在申請標章送件時，FreeGo 掃描報告中的 **Show No 錯誤次數必須為「絕對零次（0 錯誤）」**，否則系統直接拒收。 |
| **E 類代碼 (Evaluation 人工測)** | 由數發部認證之**無障礙稽核專家及視障身障檢測員**親自手動評測。 | - 純鍵盤（Tab / Shift+Tab / Space / Enter）能否遊歷全站且焦點可見。<br>- 是否存在「焦點迷航」或「鍵盤陷阱」。<br>- 使用 NVDA 螢幕報讀器朗讀語意是否順暢真實。<br>- 畫面放大至 200%–400% 時是否產生內容截斷或重疊。 | **專家實務判定**。<br>人工抽測發現任何 E 類缺失，即發出補正通知，限期未改善者不予發標。 |

## 3. 常見退件地雷與前端工程防禦清單

在實務送審金融及數據類網站時，最常見的不合規退件原因集中於以下工程細節：

1. **抹除鍵盤焦點外框（全域 outline 歸零）**：
   - ❌ 致命寫法：`* { outline: none; }` 或 `:focus { outline: none; }`。
   -  合規修正：保留或增強焦點指示器，推薦使用高對比雙層焦點圈：
     ```css
     :focus-visible {
       outline: 2px solid #ffffff;
       outline-offset: 2px;
     }
     ```
2. **非語意化標籤模擬按鈕**：
   - ❌ 致命寫法：以 `<div @click="...">` 或 `<span @click="...">` 製作按鈕，未配置 `role="button"`、`tabindex="0"` 與 `@keydown.enter`。
   -  合規修正：一律採用原生 `<button>` 元件。
3. **表單輸入框缺少關聯標籤**：
   - ❌ 致命寫法：僅靠 `placeholder="請輸入股票代碼"` 當作標籤，無任何實體 label。
   -  合規修正：配置顯式 `<label for="stock-input">`，若視覺需隱藏則套用 `class="sr-only"`（僅供螢幕報讀器讀取）。
4. **動態內容更新未通知報讀器**：
   - 即時股票報價更新或選股篩選結果刷新時，輔具使用者毫無所覺。
   -  合規修正：在動態刷新容器上配置 `aria-live="polite"`，讓報讀器在空閒時主動播報更新結果。

## 4. 標章有效期限與維護責任

- **效期 3 年**：數位發展部審查核發之無障礙標章（分為 A、AA、AAA 等級），有效期限為 **3 年**。
- **定期抽驗與撤銷**：數發部建置有全自動常態抽檢機器人；若在有效期間內，網站進行改版後爆發大量無障礙錯誤且逾期未改善，主管機關得逕行撤銷標章資格並公告。
