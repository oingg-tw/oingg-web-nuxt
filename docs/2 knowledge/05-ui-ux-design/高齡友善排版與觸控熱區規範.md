# 高齡友善排版與觸控熱區規範

> 面對 50–75 歲的近退休與銀髮投資族群，產品工程必須嚴格遵從高齡人因工程（Senior Ergonomics）約束。老化伴隨的生理轉變——包含水晶體混濁與吸光率上升（需更多光子與更大視角）、散光與老花（對比敏感度退化）、小肌肉微細震顫（精細觸控精度下降），要求介面確立「字級下限 16px」、「行高 1.5 倍」、「觸控熱區 48x48px」以及「實體手機寬度 360px 零破版」四大剛性標準。

---

## 1. 高齡字體排版四大剛性原則 (Typography Rules)

```
【傳統資料密集後台】            【高齡友善銀髮金融排版】
字級: 12px ~ 14px              字級下限: 16px (覆寫 Element Plus 預設，核心數據 18px+)
行高: 1.2x (擠壓擁擠)           行高: 1.5x (確保垂直換行呼吸空間)
行寬: 120 字元以上 (容易跳行)    行寬: 45 ~ 65 字元 (避免視線折返迷航)
對齊: 兩端對齊 (文字河流空洞)    對齊: 強制靠左對齊 (提供穩固垂直視覺錨點)
```

| 排版構面 | 專案剛性工程規範 | 生理學與認知工效依據 |
| :--- | :--- | :--- |
| **內文字級下限** | **全站文字 $\ge 16\text{px}$**<br>（專案全面覆寫 Element Plus 預設之 14px，關鍵數據建議 18px–20px） | 視網膜光受體密度隨年齡下降，14px 以下小字在視網膜成像視角過小，長者需瞇眼或縮減閱讀距離。不允許資料密集介面破例。 |
| **行高標準 (Line Height)** | **一般正文 $\ge 1.5\text{倍}$**（$16\text{px}$ 配 $24\text{px}$ 行高，緊密咬合 [[8pt 軟網格與 4pt 垂直基線系統]]） | 行間距過窄會引發相鄰文字行筆劃相互干擾（Crowding Effect），適度行高給予視網膜明確的空間留白。 |
| **單行文字行寬 (Line Length)** | **控制在 45 至 65 個半形字元**（中文約 25–35 字） | 行寬過長時，高齡者的跳視（Saccade）眼球運動極易在換行回掃時發生「跳行」或重複閱讀同一行。長文區塊必須配置 `max-width`。 |
| **文字排版對齊** | **一律採「靠左對齊（Left-aligned）」**，嚴禁兩端對齊（Justified） | 兩端對齊會在中文或英文字詞間拉出不規則的白色空隙（即文字河流 River Effect），誘發閱讀障礙與視覺疲勞。 |

## 2. 觸控目標尺寸與防誤觸安全間距 (Touch Targets)

隨著手部小肌肉精細動作控制力減弱與指尖震顫，傳統 24x24px 或 32x32px 的小按鈕極易引發高齡長者嚴重的誤點焦慮：

```
+───────────────────────────────────────────────────────────+
|               按鈕物理點擊熱區: 48px x 48px                |
|  +─────────────────────────────────────────────────────+  |
|  |           視覺可見按鈕內容 (如 36px 高度)           |  |
|  +─────────────────────────────────────────────────────+  |
+───────────────────────────────────────────────────────────+
                              ▲
                              │ 防誤觸間距 >= 8px
                              ▼
+───────────────────────────────────────────────────────────+
|               相鄰按鈕點擊熱區: 48px x 48px                |
+───────────────────────────────────────────────────────────+
```

- **WCAG 2.2 AAA / Android 實踐標準**：主要操作按鈕點擊熱區基準為 **48x48px**（最低底線不小於 44x44px）。
- **防誤觸間距**：相鄰互動元件之間必須預留至少 **8px 至 10px** 的無效觸摸間隔，杜絕長者因指尖覆蓋面積較大而誤觸相鄰的危險操作（如誤觸刪除或確認買進）。
- **杜絕精細手勢**：禁止依賴雙指捏合縮放（Pinch-to-zoom）、多指滑動或長按（Long-press）等隱晦手勢，所有功能必須提供視覺可見的實體點擊按鈕。

---

## 3. 視窗寬度適應性：360px 零破版剛性底線

- **WCAG 1.4.10 (Reflow) 底線**：要求頁面在等效 320px 寬度下「不失能且不產生二維雙向捲軸」。
- **本專案更嚴格之產品標準**：針對台灣廣大中低階 Android 長輩機（常見物理寬度為 360px），確立 **「360px 視窗下完全零破版、零元素重疊」** 的剛性測試標準。
- **資料表響應策略**：在 360px 手機寬度下，橫向寬表格自動轉化為「縱向卡片流」或鎖定首欄橫向局部滑動，徹底保護排版結構完整。
