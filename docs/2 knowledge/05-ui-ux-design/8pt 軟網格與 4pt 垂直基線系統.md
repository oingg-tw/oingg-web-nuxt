# 8pt 軟網格與 4pt 垂直基線系統

> 8pt 網格系統（8-Point Grid System）是現代數位產品設計與前端排版的數學基礎。其本質優勢在於：常見螢幕解析度縮放倍率（@1x, @1.5x, @2x, @3x, @4x）乘以 8 均為嚴格整數，能徹底杜絕次像素抗鋸齒模糊（Subpixel Anti-aliasing Blur）。專案採用「8pt 軟網格（約束 Margin / Padding / 元件高度）」搭配「4pt 文字基線垂直韻律」，建立了嚴謹且具備節奏感的一致性空間 Token 階梯。

---

## 1. 8pt 網格之數學必然性與防模糊機理

在跨裝置顯示螢幕中，作業系統常採用不同的硬體渲染縮放倍率：

| 螢幕縮放倍率 | 8pt 基準值渲染結果 | 7pt 或 9pt 不良基準值渲染結果 | 渲染效果差異對比 |
| :--- | :--- | :--- | :--- |
| **@1.0x (標準螢幕)** | $8 \times 1.0 = \mathbf{8px}$ | $7 \times 1.0 = 7\text{px}$ | 8pt 完美咬合實體像素。 |
| **@1.5x (Windows 常見縮放)** | $8 \times 1.5 = \mathbf{12px}$ | $7 \times 1.5 = \mathbf{10.5px}$ (**半像素模糊**) | 8pt 維持整數，奇數基準會產生 0.5px 跨像素抗鋸齒，使邊框模糊發虛。 |
| **@2.0x (Retina 螢幕)** | $8 \times 2.0 = \mathbf{16px}$ | $7 \times 2.0 = 14\text{px}$ | 皆為整數。 |
| **@3.0x (高階智慧手機)** | $8 \times 3.0 = \mathbf{24px}$ | $7 \times 3.0 = 21\text{px}$ | 皆為整數。 |

8 能夠被 2 與 4 均勻整除，在數學上具備最大的幾何縮放容忍度，是跨螢幕數位排版的最優最小公倍數。

---

## 2. 軟網格 (Soft Grid) vs 硬網格 (Hard Grid)

- **硬網格（Hard Grid）**：強制每個元件本體置於 8x8px 實體網格單元內，實務上極難適配多語言文字與動態內容，容易導致 CSS 佈局僵化。
- **軟網格（Soft Grid，本專案採用）**：
  - 元件本體的寬高可自適應內容。
  - **所有的外邊距（Margin）、內邊距（Padding）與元件最小尺寸，一律嚴格限定為 8 或 4 的倍數**。
  - 與現代 CSS Flexbox、Grid 盒子模型完美契合，兼具彈性與一致性。

---

## 3. 4pt 垂直文字基線韻律 (Baseline Grid)

為了讓排版擁有優雅的節奏，所有文字的 `line-height`（行高）一律嚴格約束為 **4 的倍數**：

| 文字層級與用途 | 字級大小 (Font Size) | 宣告行高 (Line Height) | 換算比例與基線狀態 |
| :--- | :--- | :--- | :--- |
| **輔助標籤 / 徽章 (Badge)** | 12px | **16px** (4 的倍數) | $1.33 \times$，文字垂直居中 |
| **次要說明文字** | 14px | **20px** (4 的倍數) | $1.43 \times$，間距平衡 |
| **全站正文基底 (Body)** | **16px** (高齡下限) | **24px** (4 的倍數) | **$1.50 \times$**，符合無障礙呼吸節奏 |
| **二級小標題 (H3)** | 18px | **28px** (4 的倍數) | $1.55 \times$，咬合 4pt 階梯 |
| **主要區塊標題 (H2)** | 24px | **32px** (8 的倍數) | $1.33 \times$，緊湊有力 |
| **首屏巨幅標題 (H1)** | 32px | **40px** (8 的倍數) | $1.25 \times$，結構分明 |

## 4. 專案標準空間 Spacing Tokens 階梯

在 CSS / Tailwind / Design Tokens 中嚴禁隨意手寫 `margin: 13px` 或 `padding: 19px`，一律調用標準 Token：

```css
--space-1:  4px;   /* 超小間距: 圖示與相鄰文字、標籤內距 */
--space-2:  8px;   /* 小間距: 按鈕內水平緊湊 Padding、表單元素相鄰 gap */
--space-3: 12px;   /* 中小間距: 卡片緊湊 padding、列表項目間距 */
--space-4: 16px;   /* 標準基準: 卡片標準 Padding、容器標準間隔 */
--space-6: 24px;   /* 大間距: 儀表板組件區塊間距、模組上下 margin */
--space-8: 32px;   /* 超大間距: 頁面主要大區塊分割、Hero 區域垂直留白 */
--space-12: 48px;  /* 巨大間距: 頁面頂部/底部主容器邊界 */
```
