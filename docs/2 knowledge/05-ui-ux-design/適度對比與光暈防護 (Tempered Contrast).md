# 適度對比與光暈防護 (Tempered Contrast)

> 「適度對比（Tempered Contrast）」是人因視覺工效學在數位介面設計中的核心工程哲學。追求無障礙並不等同於無限制地追求極限對比度（如純白 `#FFFFFF` 配純黑 `#000000` 的 21:1 極端反差）。自發光螢幕上的極限反差會引發視網膜光暈效應（Halation Effect）與眼肌痙攣，對散光、高齡退化及畏光讀者造成嚴重的視覺疲勞。最佳的無障礙實踐是將閱讀對比度收斂於 **7:1 至 12:1** 的舒適黃金區間。

---

## 1. 極端純黑白反差的生理學破壞機理

在自發光數位螢幕（OLED / LCD）上，純白背景配純黑字體，或純黑背景（`#000000`）配純白文字（`#FFFFFF`），會觸發一系列眼球光學缺陷：

```
[極端高亮文字光子 (Pure White)] ──► 穿透眼球角膜與水晶體
                                           │
                                           ▼
      【眼球微小像差與光學散射】 ──► 引發【光暈效應 (Halation Effect)】
                                           │
                                           ▼
[在視網膜成像時，白色字體筆劃邊緣向外溢出光斑，文字發生「光滲重疊」]
- 散光患者 (患病率達 47%): 筆畫重影模糊，辨讀痛苦
- 畏光症 (Photophobia) 與偏頭痛: 誘發睫狀肌劇烈痙攣
- 閱讀障礙 (Dyslexia): 觸發視覺壓力 (Visual Stress)，產生「文字河流」晃動感
```

---

## 2. 適度對比（Tempered Contrast）的工程量化標準

為在滿足甚至超越 WCAG AAA 級標準（7:1）的同時阻絕視神經疲勞，色彩架構應依環境調校至黃金區間：

| 介面主題模式 | 傳統不良極端做法 (21:1) | 適度對比工程最佳實踐 (7:1 ~ 12:1) | 視覺感知優勢與工程數值 |
| :--- | :--- | :--- | :--- |
| **淺色模式 (Light Mode)** | 純白背景 `#FFFFFF`<br>純黑文字 `#000000`<br>(對比度 21:1) | **背景**：微暖白 / 淺冷灰（如 `#F8F9FA`、`#FAF9F6`）<br>**文字**：深炭灰（如 `#1A202C`、`#212529`） | 消除面板強烈眩光，對比度維持在 **10:1 至 12:1**，文字筆劃邊緣溫和銳利而不刺眼。 |
| **深色模式 (Dark Mode)** | 純黑背景 `#000000`<br>純白文字 `#FFFFFF`<br>(對比度 21:1) | **背景**：深炭灰 `#121212` 或深藍黑 `#0D1117`<br>**文字**：[[Material 深色高度受光與文字透明度模型]]（87% 不透明度白色 `#E0E0E0`） | 消除暗室中的光暈外滲，文字與背景對比度收斂於 **9:1 至 11:1**，完美保護散光與老花讀者。 |

---

## 3. 圖表與非文字元素的對比度分級

在金融儀表板與圖表工程中，並非所有元素都應享有相同對比度：
- **正文文字與關鍵數值**：維持在 7:1 至 12:1（超越 WCAG AA 4.5:1）。
- **非文字元件邊界與圖表軸線**：嚴格維持在 **3:1 至 4.5:1**（如坐標軸標籤色票由過淺的灰提升至 `#888888`）。若邊框對比度過高，會形成強烈的網格干擾（視覺噪聲），破壞數據趨勢本身的連續性。
