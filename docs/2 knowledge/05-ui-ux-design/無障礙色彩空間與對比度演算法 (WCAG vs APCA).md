# 無障礙色彩空間與對比度演算法 (WCAG vs APCA)

> 數位無障礙色彩合規性評估，建立在量化計算模型之上。現行法定基準 WCAG 2.1 / 2.2 採用基於 sRGB 視網膜光譜加權的「相對明度（Relative Luminance）」與「算術對比度比值」，具備嚴格剛性截斷特性（4.499:1 仍判定違規）；而下一代 WCAG 3.0 引入的 APCA（Accessible Perceptual Contrast Algorithm）感知演算法，則進一步克服了 WCAG 2.x 的對稱性盲點，結合字級大小（px）、字重（100–900）與暗底光滲非對稱性，實現神經生理學維度的精準預測。

---

## 1. WCAG 2.x 法定對比度計算模型

在標準 sRGB 色彩空間中，RGB 各色彩通道值先經由分段伽瑪反校正轉化為線性光度值（$C \in \{R, G, B\}$）：

$C_{\text{linear}} = \begin{cases} \frac{C_{\text{sRGB}}}{12.92} & \text{若 } C_{\text{sRGB}} \le 0.04045 \\ \left(\frac{C_{\text{sRGB}} + 0.055}{1.055}\right)^{2.4} & \text{若 } C_{\text{sRGB}} > 0.04045 \end{cases}$

### 相對明度 ($L$) 加權方程式
$L = 0.2126 R_{\text{linear}} + 0.7152 G_{\text{linear}} + 0.0722 B_{\text{linear}}$

加權係數反映了人眼視網膜對綠光（錐細胞密集）最敏感、對藍光最遲鈍的神經光譜特性。

### 對比度公式 ($CR$)
$CR = \frac{L_1 + 0.05}{L_2 + 0.05} \quad (L_1 \ge L_2)$

其中常數 $0.05$ 用以模擬環境雜散光（Ambient Flare）在顯示螢幕表面反射造成的對比折損。

## 2. WCAG 2.x 剛性門檻與 F24 致命錯誤

| 評量規範等級 | 檢驗物件類別 | 最低對比度門檻 | 生理補償機制依據 |
| :--- | :--- | :--- | :--- |
| **WCAG 1.4.3 (AA)** | 一般文字（$< 18\text{pt}$ 或 $< 14\text{pt}$ 粗體，即 $< 24\text{px}$） | **$4.5 : 1$** | 補償 20/40 正常老化及視力退化的對比敏感度損失。 |
| **WCAG 1.4.3 (AA)** | 大尺寸文字（$\ge 18\text{pt}$ 或 $\ge 14\text{pt}$ 粗體，即 $\ge 24\text{px}$） | **$3.0 : 1$** | 低空間頻率之粗大筆畫在視網膜成像面積大，容許較低明度差。 |
| **WCAG 1.4.6 (AAA)** | 一般文字（增強級） | **$7.0 : 1$** | 補償 20/80 重度弱視族群。 |
| **WCAG 1.4.11 (AA)** | 非文字元件邊界、狀態焦點圈、圖表數據點 | **$3.0 : 1$** | 確保按鈕外框、輸入框與圖表資料可被明確定界。 |

### 剛性截斷與 F24 錯誤提醒
- **無四捨五入**：計算結果為 **4.499:1** 仍判定為違規，工程上建議安全邊界應設為 $\ge 4.6:1$。
- **WCAG F24 致命失敗**：CSS 中若僅宣告 `color` 而未宣告 `background-color`（或反之），一旦遭遇使用者瀏覽器或系統主題覆蓋，對比度將不可預期崩解，稽核工具直接判定 F24 失敗。

## 3. WCAG 2.x vs WCAG 3.0 APCA 核心演進對照

| 比較構面 | 現行法定標準 WCAG 2.x | 新世代演算法 APCA (WCAG 3.0) | 生理感知與工程實務影響 |
| :--- | :--- | :--- | :--- |
| **極性對稱性 (Polarity)** | **完全對稱**。<br>黑底白字與白底黑字對比度算出來完全相同。 | **非對稱性 (Lightness Contrast $L_c$)**。<br>正極性（亮底暗字）與負極性（暗底亮字）給予不同評分。 | 考慮了暗室中暗底亮字引發的瞳孔放大、光滲重影效應，更符合真實閱讀體驗。 |
| **字級與字重整合** | 粗糙二分法（以 18pt/14pt 粗體劃分）。 | **動態查表矩陣**。<br>根據文字具體字級（px）與字重（100 至 900）動態給予所需的最低 $L_c$ 數值。 | 徹底修正了 WCAG 2.x「極細字體（Thin 100）即便對比 4.5:1 也完全看不清」的盲點。 |
| **典型誤判案例** | **黑底純紅字（`#FF0000` on `#000000`）**：<br>WCAG 2.x 計算為 **5.25:1 (判定通過 AA)**。 | **APCA 判定 $L_c$ 極低 (直接攔截不合格)**。 | 人眼紅色光譜錐細胞在暗適應下無法提供足夠明度差，小字體在黑底上極難辨識，APCA 能有效糾錯。 |
