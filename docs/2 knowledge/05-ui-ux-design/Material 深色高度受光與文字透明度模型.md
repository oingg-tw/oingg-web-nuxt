# Material 深色高度受光與文字透明度模型

> Google Material Design 深色主題架構為現代前端介面確立了科學的深色模式標準。深色模式絕非將淺色介面直接「反相（Invert）」。在黑色背景下，傳統投射陰影（Box Shadow）無法為人眼所見，深色架構將介面層級重構為「表面受光量模型（Surface Elevation with White Overlays）」；同時為避免純白文字刺眼，確立了嚴謹的「87% / 60% / 38% 文字不透明度法則」。

---

## 1. 表面高度受光量模型 (Surface Elevation)

在深色主題中，介面的 Z 軸高度（Elevation，單位 dp）透過在基準深炭灰表面疊加不同比例的「半透明白色（`#FFFFFF`）覆蓋層」來表達——**越高的表面，離頂部虛擬光源越近，反射光越多、顏色越亮**：

```
[頂層對話框 / Modal (24dp)] ───► 疊加 16% 白色 ──► 呈現 #383838 (最亮)
             ▲
[導航列 / App Bar (4dp)] ─────► 疊加  9% 白色 ──► 呈現 #272727
             ▲
[卡片容器 / Card (1dp)] ──────► 疊加  5% 白色 ──► 呈現 #1E1E1E
             ▲
[基底畫布 / Background (0dp)] ──► 基準深灰底 ────► 呈現 #121212 (嚴禁純黑 #000000)
```

| 介面高度層級 (Elevation) | 應用元件類別 | 白色疊加層不透明度 (White Overlay) | 換算最終表面色票 HEX | 對比度安全性 (對 87% 白字) |
| :--- | :--- | :--- | :--- | :--- |
| **0dp (基底表面)** | 頁面全域 Background 畫布 | 0% (純基底) | **`#121212`** | 15.8:1 (完全合規) |
| **1dp (基礎卡片)** | 儀表板卡片、表格容器、選單背景 | 5% 白色覆蓋 | **`#1E1E1E`** | 13.5:1 (高於 AAA 級) |
| **4dp (次級浮層)** | 頂部全域導航列 (Navbar)、側邊抽屜 (Drawer) | 9% 白色覆蓋 | **`#272727`** | 11.2:1 (高於 AAA 級) |
| **8dp (下拉選單)** | 下拉選單 (Dropdown)、Tooltip 工具提示 | 12% 白色覆蓋 | **`#2E2E2E`** | 9.8:1 (高於 AAA 級) |
| **24dp (最高對話框)** | 彈出式 Modal 對話框、警告通知 Dialog | 16% 白色覆蓋 | **`#383838`** | **7.8:1** (即便在最亮頂層，仍穩健高於 WCAG AAA 7:1 門檻) |

## 2. 文字不透明度三階法則 (Text Opacity Hierarchy)

為落實 [[適度對比與光暈防護 (Tempered Contrast)]]，避免高反差光暈破壞文字邊界，深色介面的文字嚴禁一律使用 100% 純白：

| 文字層級 (Text Hierarchy) | 白色不透明度規範 (CSS rgba) | 色票等效值 (在 #121212 上) | 視覺感知功能與應用情境 |
| :--- | :--- | :--- | :--- |
| **高強調文字 (High Emphasis)** | **87% 白色** (`rgba(255, 255, 255, 0.87)`) | 約 `#E0E0E0` | **頁面標題、主要正文內文、關鍵金融數值**。<br>消除純白的刺眼光滲，文字邊緣極度柔和清晰。 |
| **中強調文字 (Medium Emphasis)** | **60% 白色** (`rgba(255, 255, 255, 0.60)`) | 約 `#A0A0A0` | **副標題、資料表欄位標籤 (Th)、次要說明資訊**。<br>提供清晰的視覺層次，避免次要資訊喧賓奪主。 |
| **停用/輔助文字 (Disabled / Low)** | **38% 白色** (`rgba(255, 255, 255, 0.38)`) | 約 `#6C6C6C` | **停用狀態按鈕、未啟用控制項、圖表輔助網格**。<br>維持最基礎的輪廓可感知性。 |

---

## 3. 品牌彩色的深色降飽和處理

在深色介面中，直接沿用淺色模式的高飽和度品牌色（如高飽和鮮紅、翠綠、亮紫）會引發**色差立體錯位震顫（Chromostereopsis）**，造成人眼感知深淺位置的錯亂。
- **降飽和規則**：彩色主題色在深色表面上必須**調降彩度 10% 至 20%**，或改用色票系統中較淺的色階（Tonal 200–300）。
- 確保彩色文字或彩色按鈕與 `#121212` 深灰表面依然滿足 WCAG 4.5:1 的法定對比標準。
