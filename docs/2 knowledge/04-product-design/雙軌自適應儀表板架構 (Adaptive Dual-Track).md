# 雙軌自適應儀表板架構 (Adaptive Dual-Track)

> 雙軌自適應儀表板架構（Adaptive Dual-Track Architecture）是為退休金融科技（Silver WealthTech）設計的資訊架構範式。為了解決「退休小白（需要心理防禦與確定性）」與「退休專家（需要穿透式因子與尾部精算）」在認知負荷與決策邏輯上的根本對立，系統放棄均質化的一刀切版面，預設提供卸載認知負擔的小白防禦模式，同時提供一鍵解鎖高階量化精算控制台的無縫通道。

---

## 1. 兩大核心用戶群之認知模型對立

| 比較構面 | 退休族小白投資人 (Novice Track) | 退休族專家投資人 (Expert Track) |
| :--- | :--- | :--- |
| **心理帳戶與思維** | 深受「心理帳戶」與「股息謬誤」支配，將資產嚴格區分為不可動用的本金與可花費的利息。極度恐懼本金受損。 | 具備完備金融計量素養，擺脫心理帳戶，專注於總報酬（Total Return）、[[序列報酬風險 (Sequence of Returns Risk)]] 與抗通膨實質購買力。 |
| **首要關注指標 (P0)** | **被動現金流日曆**、日常開銷覆蓋率、安全存續跑道年限（可支撐至幾歲）。 | **穿透式因子暴露**、有效存續期間（Duration）、最大回撤（MDD）、動態提領護欄（SWR）、VaR/CVaR 尾部風險。 |
| **資料顆粒度要求** | 宏觀功用分艙（生活備用金 / 穩定收益庫 / 長期成長艙）。底層代碼與即時行情跳動刻意隱藏。 | 微觀穿透細節（單一標的代碼、風格因子權重、跨市場利差暴險、滾動相關性矩陣）。 |
| **圖表視覺化偏好** | 圓弧指針儀表圖、月曆式入帳圖、三色進度條。 | 萬次蒙地卡羅機率扇形圖、回撤水下圖、資產滾動相關性熱圖、跨帳戶稅務流向桑基圖（Sankey）。 |
| **控制權與自動化** | 全託管自動化（Autopilot）。偏好系統自動執行再平衡，需要「第三方信任聯絡人」與一鍵直連真人顧問。 | 主動控制權。要求自訂再平衡偏離區間（Rebalancing Bands）、交互式參數滑桿（Sliders）與完整數據匯出（CSV/JSON）。 |

```
+─────────────────────────────────────────────────────────────+
                               │
       ┌───────────────────────┴───────────────────────┐
       ▼                                               ▼

  - 3 大生活功用分艙卡片                         - 穿透式風格因子 (價值/規模/低波)

```

## 3. 高齡人因工程與通用約束

無論切換至小白或專家模式，全站必須恪守針對高齡投資人生理退化的剛性工程底線：
- **視覺無障礙**：遵從 [[適度對比與光暈防護 (Tempered Contrast)]]，文字對比度 $\ge 4.5:1$，大字 $\ge 3:1$；正文內文字級下限為 **16px**（推薦 18px）。
- **觸控熱區**：遵循 [[高齡友善排版與觸控熱區規範]]，按鈕與互動熱區不得小於 **48x48px**，相鄰按鈕防誤觸間距 $\ge 8\text{px}$。
- **認知載荷防護**：單一畫面核心資訊組塊（Chunks）嚴格控制在 4–5 個以內，落實 [[金融數據降噪哲學 (Noise Elimination)]]。
