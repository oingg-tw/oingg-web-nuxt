# 價格敏感度模擬：20 位虛擬受測者

2026-09-24。每位由獨立 sub-agent 扮演並單獨訪談，報告一人一份，本檔只放**效度檢查**與**跨人結論**。
個別報告請看同目錄的 `<id>-<姓名>.md`。

## 這輪能不能用

**兩個對照組都通過。** retiree-08 蔡玉蘭與 ext-05 方美珍設計上不該付費，兩人皆未出現願付訊號。

**變異塌縮檢查：未發生。** 把 20 段第 0 題（「你怎麼決定一檔股票值不值得買？」）逐字答案取出，
以字元 bigram 做 190 組兩兩比對：

| | |
|---|---|
| Jaccard 中位數 | 0.079 |
| 最大 | 0.126（ext-01 高敏慧 × ext-08 簡孟儒） |
| 最小 | 0.004 |
| 答案長度 | 98 – 1,109 字（11 倍） |

最大的一對是設計上就重疊的側寫（都拆杜邦、都要求數字可防守），不是塌縮；同義改寫通常在 0.4 以上。
20 段開場白無一重複。重跑檢查：`scripts/`（見 git log）或直接對 `## 第 0 題原始回答` 區塊重算。

## 讀這批資料的四個陷阱

1. **需求曲線非單調，禁止外推。** retiree-12 謝宛蓉與 retiree-03 黃志明接受 599/799，卻**拒絕** 149/249。
   Gabor-Granger 的常規聚合假設單調性，會自動把他們計入「接受 149」——恰好在最低價位反轉答案，
   系統性高估低價帶需求。彙總表必須逐價位記實際作答，非單調者單獨列欄。
   附帶：他們的拒絕發生在**看到價格那一刻、註冊之前**，後台呈現為匿名跳出，**高階用戶的流失是隱形的**。
2. **兩個人的 Van Westendorp 不可併入同一分布。** ext-01（B2B，VW 問到的是個人心理帳戶而非商業決策，
   方向與她實際會簽的金額相反）、ext-07（四個數字全繞著他現在付的 333 打轉，他自己也指出了）。
3. **訪談用的是測試階梯（月 149–799／年 1,988–4,980），不是真實價目表（399／3,990，年繳折 17%）。**
   任何關於「價目表」的結論都要拿真實價位重算。
4. **Advisor 層 n=1。** 下一輪不該再測價格，該測門檻：再找 2–3 位 IFA，問「四項齊備你簽不簽」。

## 跨人結論

### A. 付款結構的效果量大於價格

- **retiree-07 吳俊賢**：月繳五個價位全拒，含最低的 149（「一塊錢我也不要自動扣」）；
  ATM 不自動續約則 1,988／2,988 接受。**去掉自動續約的增益大於把價格砍半**，因為降價在自動續扣下無效。
- **ext-06 莊文卿**：刷卡 9 個價位 0%、ATM 年繳回到金額決定的水準（3,990 接受），**100% 對 0%**。
  兩個方向都不能用價格交易：刷卡打 87 折仍拒，ATM 加 100 元手續費仍買。
  主因不是怕盜刷，是**對不到帳／授權失控**加上**那一頁我不會按**——兩者必須同時解，
  所以「ATM／超商 ＋ 一次性 ＋ 不自動續約」是**一個功能，不是三個可拆選項**（他兩半都反向驗過）。
- **ext-01 高敏慧**：這條分支有第二群完全不同的受眾——**年繳一張發票、報帳一次**。
  優先度評估要把「不刷卡的長輩」與「要報帳的專業戶」加起來算。
- **retiree-01 陳文雄**：ATM 年繳**可以定價更高**，+300～500 元他照繳，超過 500 變成「懲罰我不綁卡」。
- 未被估到的成本（ext-06）：手動續約的最小規格是**到期前 30 天主動發簡訊、內含可直接繳的代碼、全程免登入**。
  不能走 email（「我一個月看不到一次」），不能要他登入（登入牆＝流失點）。這是新外部相依，不是 cron job。
- ext-06 自己給的下一步：結帳頁放一顆**不接金流**的「我要用 ATM／超商繳款」按鈕，點了只記錄。
  一個月的點擊率就是現在缺的分母——在拿到分母前，這條分支既不排開發也不撤掉。

### B. 三條互相獨立的證據說 3,990 偏低

- **retiree-03 黃志明**：5 個拒絕裡 3 個純粹由「太便宜」產生，0 個是預算理由；主動要求漲價。
  並指出低價檔位的第二層代價：「這個價位的人要的是『告訴我買什麼』，那你們的產品路線最後一定會往那邊走。」
- **retiree-12 謝宛蓉**：懷疑門檻 300／月＝3,600／年，**3,990 只高出 11%，落在誤差範圍內**。
  第一反應是「他們是不是算錯了」。
- **ext-01 高敏慧**：低於一萬／年她要重新想我們的商業模式。

→ **1,988 對高階用戶是淨負值**（不是賺得少，是主動趕人）。促銷要用**不動標價**的形式。

**同時（retiree-12）**：合規驅動的免費層被讀成「你在賣個資」——邊際成本最高的東西免費送，
邊際成本近零的東西收費，推論鏈很短。**定價頁需要一句話說明分析免費是法規要求、不是行銷手段。**
一行文案解掉一個結構性信任問題，是本輪投報率最高的單一改動。

### C. 試用期對每個人都錯，方向各不相同——而且是排程問題不是長度問題

| 受測者 | 失效模式 |
|---|---|
| retiree-01 | 一年出手 3–5 次，**連試都不會試**；準則應是「保證涵蓋一次月營收公布日」（每月 10 日），14 天不保證 |
| retiree-11 | 太長——衝動以小時計 |
| ext-03 | 時鐘從**錯的人**身上開始算；應從被照顧者首次登入起算，或代付情境延長到 30 天 |
| ext-04 | **季節性使用者裝不進任何固定長度**（一年只動 6–8 月）→ 獲客與贏回信件排在 **5 月**，零工程成本 |
| ext-01 | 白標沒在試用期開＝她唯一在意的事驗不到，Advisor 轉換率會系統性偏低且原因不會進埋點 |
| ext-08 | 14 天**百分之百跨不到一次季報**；他自己的省錢解法是**讓他驗過去的**（攤開過去四季資料何時進來、何時被修正），不必延長 |

**不要動的一條（ext-06）**：14 天免綁卡。「如果試用就要先給卡號，我連試都不會試。」

### D. 三個付費維度，實際只有兩個在賣

- **查詢廣度**：對 retiree-01／ext-06／ext-04（各 3–4 檔持股）**價值為零**。
  但它是 **ext-03 唯一必須付費的理由**（母親持股 17 檔 > 10）與 ext-07 的硬牆。
  → **10 檔上限是承重牆，放寬到 20 檔，ext-03 這整個客群的付費理由就消失。**
- **歷史深度**：retiree-01／ext-06／retiree-03 唯一肯掏錢的東西。兩個附帶要求：
  - **這個維度目前幾乎無貨可賣**（2026-09-24 與 bff-ts 對帳、我方直打 :4000 複驗）：
    季指標 2330 有 24 期、2317／1101／2454／5876 各 23 期、6916 只有 8 期，
    要 limit=40 回傳仍封頂，**24 季是天花板不是分頁上限**；月營收 total=60，要 120 也只給 60。
    股利歷史全市場隨機抽 20 家平均 1.9 年（bff-ts 實測，大型股是有偏樣本）。
    換句話說**免費與付費拿到的是同一個 6 年**，retiree-03 要的 10 年任何價格都給不了。
    → 法規只允許的三個付費維度，實際可用的只剩兩個（查詢廣度、匯出推播）。
    在有貨之前**結帳頁不得出現「更長的歷史」**——retiree-03 說他會七天內退費並公開講。
    （更正：先前記為「2022Q1 下限、只有 2330 回溯到 109Q4」，實測是 ~2020Q3 且全市場一致，mops 已回補。）
    **逐檔差異多數是缺口不是年齡**（20 檔抽樣，同日實測）：16 檔有 22–24 季，4 檔只有 8–10 季，
    其中只有 6916（2023-12 上市）能用公司年齡解釋；8069 元太（2004 上市）、9910 豐泰（1992）、
    8046 南電（2006）都上市 20 年以上，與市場別、上市日皆無關。已轉給 bff-ts。
    這對結帳頁有影響：照實標「這一檔只有 10 季」，對一家有 22 年財報的公司而言讀起來像我們的失誤——
    而且它確實是。
  - retiree-01：免費版要顯示**總可用期間**（「本檔共 14 年，免費顯示近 5 年」）——
    「你連年數都不給我看，那我就是在賭，我不賭。」截斷時仍回傳總期間，是小改動。
- **匯出與推播**：
  - ext-04 的**唯一**付費理由是除息提醒（「我根本不用開，你會來找我嘛」）。
    付費層文案不要並列功能清單（「功能太多我會怕」），要寫「除息前我們會通知你」。
  - ext-08／retiree-03：CSV 要多一欄 **`knowledgeDate`**——bff-ts 已經有這個欄位。
  - ext-06：「CSV 是什麼？我要的是可以印出來的一張紙」→ **一段 print media query（A4、不跨頁、黑白可讀）
    的 CP 值遠高於新功能。**

### E. 續約通知不帶使用數據就是流失事件

- **ext-03**：只寫「即將續約，感謝支持」的信＝「請按這裡取消」。而且他三個月根本不會發現沒人用。
  通報時機決定歸因方向：第 30 天講 → 歸因到自己，不退訂；第 12 個月才講 → 歸因到產品，必退。
  他還要求**反轉推播方向**：現在是「市場事件→使用者」，他要「**人的事件→付款人**」
  （清單多一支代表有人在跟她講話——這是防詐不是投資），既有資料就做得到。
- **ext-04**：純日期提醒對她等於廣告。有效版本必須寫「您這個月看了三次」／「您這兩個月都沒有打開」，
  負向數字她明說接受。**這需要讀得到登入／查詢計數，是真實資料依賴，不是文案工作。**
- **舊價保留必須拆成兩份文案。** 在訂用戶（ext-07，錨還活著）半有效；
  流失用戶（ext-04）**淨負向**——她忘了自己付過多少，「還是原價」讓她推論「所以現在漲了」。
  贏回文案要直接寫金額。
- **ext-07**：漲價的成本記在**推薦行為**，不在流失率。他 100% 留存，損失的是他兩年推了四五個人的
  LINE 群獲客路徑——這筆在任何留存指標上都看不見。

### F. Pro→Advisor 的斷層在名稱不在價格

- **ext-07**：同樣 6,900，叫 Advisor 他不點進去，叫「家庭版／雙帳戶」他直接刷。
  「Advisor 這個字就在跟我說『這不是給你的』。」**中間層要用帳戶數命名，不能用職業命名。**
- **ext-07**：升級的觸發點是**撞到 quota 的那一秒**，不是價格頁也不是 email。
  升級入口掛在 quota 攔截點，文案寫增量價差不寫方案名。
- **ext-03**：家庭方案的第二個 seat 不是第二個使用者，是**監護人視角**（唯讀、以人為事件源），
  而且只值 **+50%**，不是 +100%。做成「多一個一樣的帳號」會同時錯掉定價與功能。
- **ext-01**：客戶數上限 30 對手上 28 個客戶的人是**負分**（「你不希望我長大」）。
  她怕的不是上限，是撞到上限時沒有路。
- **ext-01**：她願意付最高價的理由（資料溯源、徽章、分位座標）**依法必須免費**。
  Advisor 層能賣的是可交付物與規模，**加上她自己開的條件：報告快照（帶資料截止日＋產出時間）＋資料更正紀錄**。
  那是把「資料出錯我要扛責任」變成買得到的保險。工程上是真實新分支（不可變快照＋修訂歷史）。
  另：**沒有統編＋公司抬頭電子發票，B2B 轉換率是 0，與價格無關。**

### G. 折扣在每個分群造成的傷害都不一樣

| 受測者 | 折扣的實際產出 |
|---|---|
| retiree-11 | 「首月 99 → 原價 399」＝ 99 元 ＋ 一則負評 ＋ 一次退費請求（90% 轉換、10% 留存） |
| ext-01 | B2B 層的折扣是**供應商存續訊號**，且換到訂閱卻換掉續約理由（付 Advisor 的錢、退回 Pro 的用法） |
| ext-08 | 對競品用戶只買到**並行訂閱**；149 更是「便宜到我不用做決定我就不會認真用」＝報表上像成長、留存上是負債 |
| retiree-10 | 推薦獎勵是**負價值**：「你給我獎勵，等於把我唯一能推薦的理由拿走」 |

### H. 價格搬不動競品的付費用戶——免費也搬不動

**ext-08 簡孟儒**（本輪最重要的單一發現）：半價與**完全免費**兩題都直接測過，都是否。

> 「你在優化的是**取得成本**，但我的瓶頸是**轉換成本**。這是兩條不同的曲線。」

他自己把切換成本量化：清單半小時可搬；搬不過去的是三年調出來的 **8 組篩選條件**——
指標定義不同 → 篩出不同公司 → 整組要重新校準，8–10 小時 ×1,000 ＝ 一次性一萬元。
「我搬過去第一年的真實成本是一萬三千九，不是三千九。」

**能搬動他的是一個「對帳」頁**：「你不用比它好，你只要告訴我它哪裡跟你不一樣、以及為什麼——
『這檔 ROE 我們算 18.2%，某站算 19.4%，差在分母我們用四季平均、他們用期末』。」
他願意**同時付兩邊**只為了能對帳，半年後對帳都是我們對，他就退掉競品。

→ 要做「競品匯入」的話，該做的**不是清單 CSV 匯入**（最不重要的半小時），
是把對方的篩選條件翻譯成我方欄位並明寫定義差異與預期筆數變化。
現有 `/metrics` 的 definition／source 與 `metricCode.basis` 欄位 ID 就是這件事的基礎設施。

## 最便宜的九件事（都已有資料或純排程）

1. 定價頁一句話：分析免費是**法規要求**，不是行銷手段（retiree-12）
2. CSV 匯出加一欄 `knowledgeDate`（ext-08、retiree-03；bff-ts 已有此欄位）
3. 截斷歷史時仍顯示**總可用期間**（retiree-01）
4. 結帳頁標**具體起始年／季數**，不寫「更長的歷史」（retiree-03，撞上 2022Q1 下限）
5. 獲客與贏回信件排在 **5 月**（ext-04）
6. 升級入口掛在 **quota 攔截點**，寫增量價差（ext-07）
7. 中間層用**帳戶數**命名，不用職業命名（ext-07）
8. 一段 **print media query**（A4、不跨頁、黑白可讀）（ext-06）
9. 結帳頁一顆**不接金流**的 ATM／超商按鈕，用點擊率量分母（ext-06）
