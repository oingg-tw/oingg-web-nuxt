# retiree-04 張秀蘭（72 歲，高雄三民區獨居家管，靠遺屬年金與兒子每月給的一萬）

## 這位封住的缺口

她是唯一一位**不在價格軸上作答**的受測者：價格問題一出現就被歸類成詐騙風險，然後轉介給兒子。沒有她，就測不到「付錢的人不是使用者」這個情境，也測不到免費層本身會被讀成詐騙話術開場的可能。

## 第 0 題原始回答（變異塌縮檢查用）

問：「你怎麼決定一檔股票值不值得買？」

> 「我無買過啦。你問我按怎決定……我攏無決定，彼是阮翁留落來的。伊生前佮我講台積電莫賣，我就無賣，就按呢。啊那个 00878 是阮後生幫我買的，伊講一個月會配寡錢予我，我就講好，我也無問伊是啥物。我家己是袂曉看啦，我連手機彼个字我都愛放到上大。
>
> 啊你問我值不值得買喔——我是按呢想啦，阮翁留的我就毋敢振動，我驚我一振動就變少，錢變少我就對不起伊。若是要閣買新的，我一定先問阮後生，伊講會使我才買，伊講毋好我就毋好。
>
> 閣有啦，阮隔壁彼个太太舊年予人騙一百外萬，就是 LINE 內底有人教伊買股票，講穩賺的，講甲喙角全泡。所以我這馬聽著股票兩字就先驚一下。」

（主持人註：全程未出現任何指標、財報、殖利率等詞彙。她對第 0 題的回答是「我不決定」——這本身就是資料，不是拒答。）

## 現有支出錨點

**投資資訊支出：0 元，且是硬性的 0。**

問她每個月有哪些固定要繳的錢、怎麼繳：

> 「電話費三百外，第四台以前四百外，阮後生舊年共我停掉，講電視有網路就會使看。水電兩個月一擺。這攏是紙單仔寄來，我攏提去 7-11 繳，行路五分鐘就到矣。錢我是提現金去繳的。」

問她為什麼在投資資訊上一毛都不花：

> 「電視都有咧報矣啊，非凡彼台規工咧講。閣講，網路頂懸要錢的彼攏是詐騙啦，我攏無咧點。阮後生嘛有交代我，叫我毋通亂點。」

錨點結構：她有能力也有習慣支付**紙本帳單 → 超商 → 現金**這條路徑的固定費用，金額落在 300–500 元／月。她沒有任何訂閱、沒有信用卡自動扣款經驗，郵局轉帳也要兒子幫忙。

## Gabor-Granger 結果

報價前已說明：免費版個股頁的全部分析內容、篩選結果筆數、月營收與除權息行事曆都不鎖，付費只放寬清單數量、歷史深度、匯出推播。

### 月繳（隨機順序：399 → 149 → 799 → 249 → 599）

| 價位 | 會訂？ | 她的原話 |
|---|---|---|
| NT$399 | 不會 | 「這要錢喔？……三百九是每一個月攏愛喔？彼比我的電話費閣較貴呢。莫啦莫啦。」 |
| NT$149 | 不會（實質為「我問我兒子」） | 「一百四……錢是無蓋濟啦。毋過你講的彼个自動扣，是逐個月家己走去我的簿仔提喔？彼我毋敢。我毋知伊會扣到當時。我問阮後生。」 |
| NT$799 | 不會 | 「（笑）七百九？彼我一禮拜的菜錢呢。你是咧講笑。」 |
| NT$249 | 不會（「我問我兒子」） | 「兩百四嘛是愛逐個月扣乎？……我共你講，我無卡。我連卡攏無，是要按怎扣。」 |
| NT$599 | 不會 | 「五百九喔，彼我毋免聽矣。」 |

**月繳全數 0 個「會」。但拒絕的理由在 149 與 249 這兩檔換了性質**：不是嫌貴，是「每個月自動從我的簿仔提錢」這件事本身。她問的是「會扣到什麼時候」，不是「一個月多少」。

### 年繳（隨機順序：2,988 → 4,980 → 1,988 → 3,990）

| 價位 | 會訂？ | 她的原話 |
|---|---|---|
| NT$2,988 | 不會 | 「兩千九喔……彼差不多是我一個月的菜錢。一擺提彼濟出去，我會袂睏得。」 |
| NT$4,980 | 不會 | 「五千？免講矣。阮後生一個月才予我一萬。」 |
| NT$1,988 | **條件式「會」——錢由兒子出** | 「一千九百八，一年才一擺乎？閣會使提去 7-11 繳彼種的？……按呢我聽有。一年一擺、繳了就煞、袂閣家己扣——彼我敢。毋過錢是阮後生出的，你愛去問伊。伊若講好，我就用。」 |
| NT$3,990 | 不會 | 「三千九……（沉默）我閣是問阮後生好矣。我家己是感覺傷濟。」 |

**唯一一個非否定的回答出現在 1,988 年繳＋超商一次繳清，而且她當場就把付款責任推給兒子。**這不是願付金額，這是「我不反對兒子替我出這筆錢」。1,988 這個數字換算成她自己的錨點是一年 165 元／月，剛好落在她電話費之下。

## Van Westendorp（**僅供下限參考**）

VW 的交點在定義上最小化拒絕率而非營收，受訪者在假設情境下本來就會低報；這位又完全沒有訂閱錨點，四個數字的資訊量比其他受測者更低。要她直接講金額幾乎問不出來，是先用「電話費一個月三百外」當比較基準才有數字。

| 題目 | 她的數字（每月） | 她自己的說明 |
|---|---|---|
| 太便宜到懷疑品質 | **0 元（免費）** | 「免錢的上貴啦。LINE 彼个群組嘛是頭起先免錢，教你教甲你共錢提出去，後壁才開始欲錢。所以我聽著攏免錢，我是驚，毋是歡喜。」 |
| 很划算 | 100 元 | 「一百箍，差不多是我一禮拜買菜的找錢。」 |
| 有點貴但會考慮（＝會去問兒子） | 200 元 | 「兩百我會去問阮後生，我家己袂做主。」 |
| 太貴不考慮 | 300 元 | 「超過我的電話費我就莫矣，電話我一定愛用，這个毋是一定愛用的。」 |

**最需要注意的是第一題完全反轉**：一般受測者「太便宜 → 懷疑品質」，她是「免費 → 懷疑動機」。她對免費的疑慮不是品質疑慮，是詐騙漏斗疑慮。

## 結構題（只問跟她相關的）

**Q：ATM／超商一次年繳（不自動續約） vs 信用卡自動續扣？**
> 「彼个自動扣的免講，我無卡，就算有我嘛毋敢。超商彼个我會曉，我逐個月攏咧繳水電，提單仔去櫃台，人共我掃一下就好矣。」
問她超商繳的重點是不是比較方便，她說不是：
> 「毋是方便啦，是繳了就煞。伊袂閣家己去提我的錢。」

**Q：七天無條件退費？**
> 「退錢喔……（停頓）欲退愛按怎退？愛拍電話喔？我上驚拍去彼種電話，對面講一堆我聽無的。伊若毋退我嘛無法度。」
追問：如果是兒子幫你辦退費呢？
> 「彼就無仝矣，伊會曉。」

**七天退費對她本人的說服力接近零，對她兒子才有說服力。**

**Q：14 天免綁卡試用？**
> 「免卡喔？彼會使。毋過嘛是愛阮後生先用看覓，伊講有路用我才用。我家己看攏看無。」

**Q：如果是兒子付錢、帳號給你用，你用你的手機看？**
> 「按呢上好啊。伊逐禮拜來兩擺，伊會使共我設定好勢。我只是要看阮翁留彼个這馬值偌濟、閣有當時會有錢入來。其他彼我攏免。」

**Q：試用到期以後資料會留著，只是不能再加新的？**
> 「留著就好。我上驚的是我按一下，阮翁留彼个就無去矣。」

## 反對意見的形狀

她的拒絕不是「太貴」，是**三段式的分類動作**，而且每一段都可以獨立擋死成交：

1. **偵測**：「這要錢喔？」——「要錢」這個訊號一出現，話題就從投資工具換軌到詐騙防範。
2. **歸類**：拿隔壁太太被騙一百多萬、LINE 群組先免費後要錢的既有經驗來套。她的判準是過去發生過的具體事件，不是這個網站的條款寫什麼。
3. **轉介**：「我問我兒子。」——這不是拖延，是她的正式決策程序終點。她不會再回來給你一個 yes/no。

**整場訪談她沒有講過一次「貴」以外帶有金額比較意味的評估語言；五個月繳價位裡有三個她連數字都沒重複一遍就否決了。**在價格軸上，這位是沉默的。她會動的是信任軸（誰在收錢、會不會一直收）跟代理軸（兒子說可以嗎）。

## 結構性發現

**1. 免費層對她是風險訊號，不是漏斗入口。**
她的詐騙腳本就是「先免費、後要錢」，所以免費版愈大方，愈像那個腳本。對應的產品決定不是加值，是加身分：公司登記名稱、負責人、實體地址、市話客服要出現在**頁面本體而非 footer**，並且絕對不能用「限時免費」「穩賺」「保證」這類文案——那會直接命中她的比對樣板。另外，「免費與付費的分析內容完全一樣」這句話對她是反效果的，她會問「按呢你賺啥？」，收費理由必須講得出來。

**2. 付費者 ≠ 使用者，需要的是帳號結構不是價格。**
她唯一的非否定回答附帶「錢是我兒子出的」。如果結帳流程只支援「本人刷卡、本人自動續扣」，這一群的轉換率是 **0 而不是低**——不是價格沒踩到，是路徑不存在。需要的是：他人代付／贈送一年、由子女在自己的裝置上完成設定與登入、到價與除息通知寄給子女（她收到 LINE 訊息只會更緊張）。這條同時也是 ext-03（兒子那一端）要驗的同一個機制。

**3. ATM／超商年繳的價值不是便利，是「不自動續約」本身。**
她講得很清楚：「毋是方便啦，是繳了就煞。」超商繳費是她生活中唯一能獨力完成的付款動作（紙單 → 走五分鐘 → 現金），而它的心理功能是**終止性**：一次付完、帳號不再有權限碰她的錢。信用卡定期定額對她不是次佳選項，是禁區。工程上這代表超商／ATM 年繳不能做成「先綁卡再選其他方式」的次級路徑，也不能在繳費成功後寄出任何看起來像續約的訊息。

**4. 七天退費與平滑降級的收件人是子女，不是她。**
退費對她無效，因為她無法想像自己執行退費流程（她怕打客服電話）。平滑降級則相反，**「既有資料全部保留」是她全場最強的正面反應**——她怕的不是損失訂閱，是「我按一下先生留下的東西就不見了」。所以這兩條文案應該分開投放：退費保證寫給付錢的子女看（降低他替母親下單的風險），資料保留寫在她會看到的介面上（降低她操作時的恐懼）。

## 與設計者假設的對照

假設寫的是「價格敏感度：**極高**；收入低、依賴子女、對線上付費有詐騙疑慮；代表價格帶最下緣與『付費者≠使用者』情境」。

**方向符合，但機制不同，而且這個差別會影響定價結論的用法。**

「極高敏感度」暗示的是一條很陡的需求曲線——降價就有轉換。她不是這樣：她在 149 元跟 799 元的拒絕理由**不是同一種**，799 是嫌貴（真價格反應），149 是怕被一直扣（信任反應）。把她記成「願付 ≈ 0」會讓分析誤以為再降價就能拿到她，實際上降到 49 元她一樣不會自己買，而 1,988 年繳超商付她卻沒有反對。

**正確的記法是：她的願付金額不存在，存在的是她兒子的。** 她在這輪的用途不是撐住價格帶下緣，是證明價格帶下緣這個概念對她不適用——她要的是另一條結帳路徑。假設裡的「付費者≠使用者」那半句完全命中，「價格帶最下緣」那半句我認為是 persona 寫得準、但假設的歸因寫得不準。

（附帶：她的認知風格預測「不談價格，直接歸類成詐騙風險：我問我兒子」——訪談中出現了三次「我問阮後生」，且第 0 題完全沒有指標語言，與預測一致，沒有看到往標準答案回歸的跡象。）
