## 一句話

**價格不是主要變數。** 決定成交與否的依序是：付款結構 → 敘事框架 → 方案名稱 → 金額。
而目前定價**偏低**（三條互相獨立的證據），三個法規允許的付費維度**實際只剩一個在運作**。

## 這批資料能不能用

兩個對照組（retiree-08、ext-05）皆未出現願付訊號。
變異塌縮檢查未發生：20 段第 0 題逐字答案的 190 組字元 bigram 兩兩比對，
Jaccard 中位數 **0.079**、最大 **0.126**，長度 98–1,109 字，開場白無一重複。
（同義改寫通常落在 0.4 以上。）

## 五個會改變決定的發現

### 1. 付款結構的效果量大於價格

retiree-07：月繳五個價位**全拒，含最低的 149**（「一塊錢我也不要自動扣」）；
ATM 不自動續約則 1,988／2,988 接受。**去掉自動續約的增益大於把價格砍半。**

ext-06 更極端：刷卡九個價位 **0%**、ATM 年繳 3,990 成交。而且**兩個方向都不能用價格交易**
——刷卡打 87 折仍拒，ATM 加 100 元手續費仍買。主因不是怕盜刷，是對不到帳＋「那一頁我不會按」。

→ ATM／超商 ＋ 一次性 ＋ 不自動續約是**一個功能，不是三個選項**。
→ 隱藏成本：手動續約要**到期前 30 天發簡訊、內含可繳代碼、全程免登入**（不能 email、不能要他登入）。
→ n=1，先用一顆**不接金流**的按鈕量分母再排開發。

### 2. 定價偏低——三條互相獨立的證據

| 受測者 | 證據 |
|---|---|
| retiree-03 | 5 個拒絕裡 3 個純由「太便宜」產生，0 個是預算理由；**主動要求漲價** |
| retiree-12 | 懷疑門檻 3,600／年，3,990 只高 11%；第一反應是「他們是不是算錯了」 |
| ext-01 | 低於一萬／年就要重新評估我們的商業模式 |

**1,988 對高階用戶是淨負值**（不是賺得少，是主動趕人）。促銷要用**不動標價**的形式。

retiree-03 另外警告：低價檔位會把產品往投信投顧法紅線那側拖
——「這個價位的人要的是『告訴我買什麼』」。

### 3. 三個付費維度，實際只剩一個在運作

| 維度 | 狀態 |
|---|---|
| 歷史深度 | **無貨可賣**。~24 季是天花板，免費與付費拿到同一個 6 年 |
| 匯出與推播 | **尚未實作**（bff-ts 確認整個 repo 沒有 CSV 匯出） |
| 查詢廣度 | **唯一在運作的** |

所以免費層 **10 檔觀察清單是承重牆**。ext-03 母親持股 17 檔，那是他唯一必須付費的理由；
他明說放寬到 20 檔他的付費理由就消失。10 與 20 之間不是「寬鬆一點」的差別，
是**有沒有人要付錢**的差別。

（歷史深度另有 ~15% 檔案存在**可修的**回補缺口——8069／9910／8046 上市 20 年以上卻只有 8–10 季
——那與天花板是兩件事，別混為一談。）

### 4. 價格搬不動競品的付費用戶，免費也搬不動

ext-08：半價與**完全免費**兩題都測過，都是否。
> 「你在優化的是**取得成本**，但我的瓶頸是**轉換成本**。這是兩條不同的曲線。」

他的切換成本是 8 組篩選條件的**語意**（定義不同→篩出不同公司→整組重新校準），8–10 小時＝一萬元。
「我搬過去第一年的真實成本是一萬三千九，不是三千九。」

**唯一能搬動他的是一個「對帳」頁**：「你不用比它好，你只要告訴我它哪裡跟你不一樣、以及為什麼。」
他願意同時付兩邊只為了能對帳，半年後對帳都是我們對，他就退掉競品。

→ 要做競品匯入，該做的**不是清單 CSV 匯入**（最不重要的半小時），
是把對方的篩選門檻翻成我方欄位並明寫定義差異。

### 5. 試用期對每個人都錯，方向各不相同——而且是排程問題不是長度問題

| | |
|---|---|
| retiree-01 | 一年出手 3–5 次，**連試都不會試**；準則應是「保證涵蓋一次月營收公布日」 |
| retiree-11 | 太長——衝動以小時計 |
| ext-03 | 時鐘從**錯的人**身上開始算（應從被照顧者首次登入起算） |
| ext-04 | **季節性使用者裝不進任何固定長度**（一年只動 6–8 月）→ 獲客排 **5 月**，零工程成本 |
| ext-01 | 白標沒在試用期開＝她唯一在意的事驗不到 |
| ext-08 | 14 天**百分之百跨不到一次季報**；他的解法是**讓他驗過去的**，不必延長 |

**不要動的一條**：14 天免綁卡。ext-06：「如果試用就要先給卡號，我連試都不會試。」

## 不要做的事

- **不要降價促銷。** retiree-11：「首月 99 → 原價 399」＝ 99 元 ＋ 一則負評 ＋ 一次退費請求。
  ext-08：149 讓他「便宜到我不用做決定就不會認真用」＝報表上像成長、留存上是負債。
  ext-01：B2B 層的折扣是**供應商存續訊號**。
- **不要做推薦獎勵。** retiree-10：「你給我獎勵，等於把我唯一能推薦的理由拿走。」
- **不要寄只有日期的續約通知。** ext-03：那封信等於「請按這裡取消」。
  有效版本必須帶使用數據（「您這兩個月都沒有打開」），那是**資料依賴，不是文案工作**。
- **不要對流失者說「保留您的原價」。** ext-04 忘了自己付過多少，推論出「所以現在漲了」——**淨負向**。
  贏回文案要直接寫金額。在訂用戶（ext-07）才適用。
- **不要放寬 10 檔上限。**（見發現 3）

## 讀這批數字的四個陷阱

1. **需求曲線非單調，禁止外推。** retiree-12／retiree-03 接受 599/799 卻**拒絕** 149/249。
   Gabor-Granger 常規聚合假設單調性，會把他們計入「接受 149」——**恰好在最低價位反轉答案**。
   而且他們的拒絕發生在**註冊之前**，後台只看得到匿名跳出：**高階用戶被低價趕走是結構上看不見的。**
2. **ext-01 與 ext-07 的 Van Westendorp 不可併入同一分布**（一個問到的是個人心理帳戶而非商業決策，
   一個四個數字全繞著他現在付的 333 打轉）。
3. **訪談用的是測試階梯（月 149–799／年 1,988–4,980），不是真實價目表（399／3,990）。**
4. **Advisor 層 n=1。** 下一輪不該再測價格，該測門檻。
