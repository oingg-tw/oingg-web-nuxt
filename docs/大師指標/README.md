# 大師指標頁面作業須知與功能設計規範 (Guru Indicators)

- **路由端點**：`/guru-indicators`
- **頁面檔案**：`app/pages/guru-indicators.vue`
- **當前狀態**：功能骨架殼（顯示「功能開發中，敬請期待」）。
- **專屬元件**：`app/components/shared/IconHexagon.vue`（自訂六角形 SVG 圖示）。

---

## 1. 核心定位與最高法規防禦原則 (Compliance Firewall)

前端工程師在重構或實作大師指標功能時，**必須誓死捍衛一項剛性架構原則**：

> 🚨 **法規鐵律：雷達圖評分的對象是「使用者所挑選的【指標策略組合】本身」，絕對不可評分「任何一檔具體個股」！**

### 為什麼這項設計至關重要？
依據 [[投顧法第 4 條安全港與釋字 634 號邊界]]，未經特許經營證券投資顧問業務屬刑事重罪（第 107 條，最高 5 年徒刑）：
- ❌ **違法情境**：若輸入「2330 台積電」，系統自動產出六角雷達圖並輸出綜合得分 95 分、標註「大師強力推薦」，直接踩中「對個別有價證券提供分析意見與推介建議」的司法紅線。
-  **合法安全港**：使用者在介面挑選了「ROE > 15%」、「負債比 < 50%」與「連配 10 年」，系統以六角雷達圖分析「**這套指標組合在財務學上的均衡性（如成長性充足、但防禦性偏弱）**」，並提供客觀知識解讀。這屬於純粹的「技術與投資理論教學」，100% 豁免於投顧業務監管。

## 2. 功能架構與六角雷達圖維度模型 (Hexagonal Taxonomy)

未來功能重啟時，六角雷達圖應錨定金融基本面六大客觀維度：

```
                    【1. 獲利品質 (ROIC / ROA)】
                               ▲
                               │
【6. 股息持續性】 ◄───────────┼───────────► 【2. 價值安全邊際 (P/B, P/E)】
   (連配年數/殖利率)            │              (常態化估值)
                               │
【5. 護城河定價權】 ◄───────────┼───────────► 【3. 財務體質 (Z-Score)】
   (毛利率穩定度)              │              (負債比/流動比)
                               ▼
                    【4. 營運成長動能 (EPS YoY)】
```

| 雷達圖維度 | 對齊知識庫核心理論 | 指標量化代表範例 | 策略健康度評估邏輯 |
| :--- | :--- | :--- | :--- |
| **1. 獲利品質** | [[ROIC-WACC 價值創造模型]] | ROIC、NOPAT Margin、ROA | 檢驗指標組合是否關注企業本業資產之超額經濟租創造能力。 |
| **2. 價值安全邊際** | [[常態化獲利與財報回溯年限]]、[[PBR 1倍破淨機制與資本收益性]] | 10年平滑 P/E (CAPE)、歷史 P/B 分位 | 檢驗是否具備葛拉漢防禦型安全邊際，避免追高於景氣循環巔峰。 |
| **3. 財務體質** | [[Altman Z-Score 破產預警模型]] | 負債比率、利息保障倍數、流動比 | 檢驗指標組合對財務違約與信用風險的防護力。 |
| **4. 營運成長動能** | [[營運槓桿與產能利用率效應]] | 月營收 YoY、近四季 EPS 成長率 | 檢驗是否捕捉跨越損益兩平點之正向營運槓桿。 |
| **5. 護城河定價權** | [[PPI-CPI 剪刀差與毛利率敏感度]] | 毛利率前期比改善、定價轉嫁能力 | 檢驗是否具備抵禦停滯性通膨與成本上升之微觀屏障。 |
| **6. 股息持續性** | [[總報酬提領 vs 高股息現金流]] | 連續配息年數、FCF 股利覆蓋率 | 檢驗是否能提供退休期穩定現金流支撐。 |

## 3. 大師經典角色預設模版 (Guru Presets)

使用者可一鍵套用投資大師的思考維度，於雷達圖即時展開對比（參閱 [[選股 Preset 分類矩陣與付費分層]]）：
- **巴菲特護城河模版**：極端強化「獲利品質 (ROIC)」與「定價權」，對成長動能適度容忍。
- **葛拉漢深度價值模版**：極端強化「安全邊際 (Net-Net)」與「財務體質」，淡化短期成長性。
- **彼得林區 GARP 模版**：追求「PEG < 1.0」之估值與成長動能高度均衡。

## 4. UI/UX 與圖表工程規範

- **六角形幾何資產**：`app/components/shared/IconHexagon.vue` 必須支援動態 `currentColor` 繼承，於導航列（16x16px）與卡片標題（24x24px）保持像素銳利度。
- **雷達圖無障礙對比**：
  - 雷達圖背景多邊形網格線顏色一律設定為 `#404040`（對 `#121212` 達成 3:1 邊界對比）。
  - 填色區域採半透明填色（`rgba(99, 102, 241, 0.25)`），輪廓線加粗至 2px，並於 6 個頂點節點繪製實體圓形錨點（Radius 4px），符合 [[多維視覺冗餘編碼 (Visual Redundancy)]]。
- **高齡觸控適配**：維度加減勾選按鈕點擊面積 $\ge 48\text{x}48\text{px}$，在 360px 手機寬度下，雷達圖自動縮放寬度為 100%，文字標籤維持 16px 以上無損呈現。詳見 [[高齡友善排版與觸控熱區規範]]。
